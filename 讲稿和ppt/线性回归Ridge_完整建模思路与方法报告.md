## 1. 研究定位与回答的问题

### 1.1 一句话定义

用带 **L2 正则的 Ridge 线性回归**，对全部 92 个注册字段联合拟合横截面预测分数，再按统一多空协议评价样本外 Rank IC 与成本后收益。

### 1.2 它专门回答什么

> **相对「不挑因子的等权平均」，数据驱动的线性权重能否更有效地整合弱信号？这种改善能否在 5bps 成本后变成净收益？**

| 问题 | 由谁回答 |
|------|----------|
| 某一个字段单独有没有预测力？ | 单因子排序 |
| 不挑因子、等权平均够不够用？ | 等权多因子 |
| **数据驱动加权组合如何？** | **Ridge（本模型）** |
| 非线性阈值 / 产业关系 / 时序？ | 树 / HCGNN / Conv–Transformer |

### 1.3 是 / 不是

| 是 | 不是 |
|----|------|
| 92 字段联合线性预测器 | 单因子排行榜 |
| L2 收缩下的学习权重 | 无正则 OLS（主口径） |
| 折内选 \(\alpha\)、折外纯测试 | 按测试年调 \(\alpha\) 或删特征 |
| 学习型线性基准（Baseline） | 已证明可实盘盈利的 Alpha |

综合报告判断逻辑：

- 若 Ridge **高于等权** → 学习权重有预测增量（支持 H2 预测层）  
- 若成本后仍差 → 问题在执行摩擦或信号经济强度，而不只在「有没有学权重」

## 2. 建模思路与设计哲学

### 2.1 为什么选 Ridge 而不是 OLS / 直接非线性

1. **92 维 + 局部高相关**（|\(\rho\)| 可 > 0.90）：OLS 系数不稳，L2 收缩必要。  
2. **低信噪比金融截面**：强正则优先于复杂非线性，先建立可解释线性上限。  
3. **与等权形成干净对照**：唯一关键差异是「权重是否由标签学习」；数据、标签、折、组合、成本相同。  
4. **为树/深度模型垫地板**：若 Ridge 已整合大部分线性信息，非线性必须证明额外增量。

### 2.2 目标选择：为什么拟合排名而不是原始收益

- **训练目标**：`target_cs_rank_5d`（同日横截面中心化未来 5 日收益排名，映射到 \([-1,1]\)）  
- **策略评价**：`future_return_5d`（真实合约开盘→开盘收益）

原因：组合层只交易排序尾部 20%；直接拟合原始收益易被极端值主导，拟合截面排名与 Rank IC / 多空排序更对齐。

### 2.3 设计原则

- 全部注册字段进入回归，**不按标签删列**（共线性交给 \(\alpha\)）。  
- 每个外层折：训练窗**最后一年**内层验证选 \(\alpha\)；**外层测试年不参与选参**。  
- 输出统一接口 `decision_date, product, prediction`，持仓与成本由执行引擎生成。

## 3. 数据基座与特征接口

### 3.1 数据来源

| 项目 | 设定 |
|------|------|
| 交接包 | `training_handoff/` |
| 特征 | `ml_features_development.csv.gz` |
| 标签 | `labels_development.csv.gz` |
| 注册表 | `ml_feature_registry.csv`（全部 92 字段） |
| 折定义 | `fold_definitions.csv` |
| 品种 / 区间 | 30 品种；2015-01-05 — 2024-12-31（开发矩阵） |

本模块**只消费 handoff 矩阵接口**，不在模块内重算因子或标签。

### 3.2 输入字段

| usage_type | 数量 |
|------------|-----:|
| predictor | 36 |
| quality_flag | 45 |
| risk | 6 |
| conditional | 5 |
| **合计** | **92** |

`__missing` 等 quality_flag 作为 0/1 特征列保留；与协议「相关字段不物理删除」一致。

### 3.3 特征预处理

| 项目 | 设定 |
|------|------|
| handoff | 横截面 Median–MAD Z-Score + clip \(\pm 5\) |
| 模型侧缺失 | 有效观测参与拟合/预测；实现中可对缺失填 0 后标准化拟合（见 2025 补充报告表述） |
| 中性化 | 未做行业/板块全局中性化 |

### 3.4 标签

\[
y^{(5)}_{i,T}
=
\frac{\mathrm{Open}_{c,T+6}}{\mathrm{Open}_{c,T+1}}-1
\]

训练用其截面排名版 `target_cs_rank_5d`；回测用原始 `future_return_5d`。

## 4. 模型架构与训练细节

### 4.1 优化目标

\[
\hat\beta
=
\arg\min_{\beta}
\sum_{(i,t)\in\mathcal{T}}
\big(y^{\mathrm{rank}}_{i,t}-x_{i,t}^{\top}\beta\big)^{2}
+
\alpha\|\beta\|_{2}^{2}
\]

其中 \(y^{\mathrm{rank}}\) 为 `target_cs_rank_5d`，\(x\) 为 92 维注册特征。

### 4.2 处理流水线

```text
handoff 92 维特征
    ↓
外层折 t = 2019…2024（扩展窗口）
    ↓
训练窗：label_end_date_5d < valid_start（purge）
    ↓
内层：训练窗最后一年，按日均 Rank IC
      从 α ∈ {0.01, 0.1, 1, 10, 100} 选最优
    ↓
用选定 α 在（净化后）训练窗重拟合 Ridge
    ↓
测试年输出 prediction
    ↓
统一执行引擎：前后 20% 多空 · 5 日调仓 · 成本情景
```

### 4.3 超参数与选参结果（开发期）

| 项 | 值 |
|----|-----|
| `alpha_grid` | `{0.01, 0.1, 1.0, 10.0, 100.0}` |
| `fallback_alpha` | `1.0` |
| 各折选中 α | 2019–2022：`100`；2023：`1`；2024：`0.1` |
| 内层准则 | 训练窗末年日均 Rank IC 最大 |
| 持有 / 调仓 | 5 / 5 |
| 多空比例 | 0.2 |

说明：\(\alpha\) 从早期折的 100 降到 2024 的 0.1，提示最优收缩强度随样本与市场状态变化；**不能简单解释为「模型逐年学得更好」**，也可能是特征关系漂移或内层验证噪声。

### 4.4 防过拟合机制

| 机制 | 作用 |
|------|------|
| L2 正则 | 抑制共线性与高维噪声 |
| 内层/外层隔离 | 测试年不选 \(\alpha\) |
| Expanding-Window + purge | 防标签穿越与随机泄露 |
| 不在 OOS 筛特征 | 特征宇宙事前冻结 |
| 无信号平滑 / 无额外交易补丁 | 胜负归因于线性预测器本身 |

## 5. 样本外验证与防窥视纪律

| 项目 | 设定 |
|------|------|
| 外层 | 2019–2024 扩展窗口 |
| 净化 | `label_end_date_5d < valid_start` |
| 内层选 α | 仅训练窗最后一年 |
| 2025 | 特征清单、执行、α 网格冻结后一次补充回测；α 仍只在 2015–2024 内选择 |
| 禁止 | 用 2025 回头改特征 / α / 持仓规则后再重报 |

2025 补充中：内层验证年 = 2024，网格内选中 **α = 0.01**（内层 IC 已偏弱，按规则选「最不差」者，未偷看 2025）。

## 6. 组合执行与成本协议

与单因子 / 等权 **完全同一执行引擎**：

| 项目 | 设定 |
|------|------|
| 时点 | T 收盘 Ridge 预测 → T+1 开盘 |
| 多空 | 最高/最低各 20%；两侧绝对权重各 0.5；组内等权 |
| 调仓 | 每 5 日；持有 5 日；无 EMA、无中位数止损 |
| 成本 | 主口径单边 5bps；敏感性 0/3/5/10 |
| 换手假设 | 调仓日往返换手取 2.0 |

## 7. 实证结果

### 7.1 开发期样本外（2019–2024）

| 指标 | 数值 |
|------|-----:|
| 样本外记录 / 交易日 / 调仓日 | 43,234 / 1,450 / 293 |
| 平均 Pearson IC | 0.0239 |
| 平均 Rank IC | **0.0247** |
| Rank IC 胜率 | 54.48% |

成本敏感性：

| 成本 | 年化收益 | Sharpe | 最大回撤 | 胜率 |
|------|--------:|-------:|--------:|-----:|
| 毛收益 | 3.25% | 0.397 | −13.73% | 54.61% |
| 0 bp | 3.25% | 0.397 | −13.73% | 54.61% |
| 3 bp | 0.22% | 0.027 | −21.40% | 52.22% |
| **5 bp（主口径）** | **−1.79%** | **−0.219** | **−26.14%** | **49.15%** |
| 10 bp | −6.83% | −0.836 | −38.93% | 46.42% |

**解读：**

- Rank IC ≈ 0.0247，明显高于等权（0.0163）与典型单因子中位数（0.0065）→ **学习权重有预测增量（H2 预测层支持）**。  
- 毛 Sharpe ≈ 0.40，略高于等权；但 3bps 已接近打平，**5bps 转负** → 预测增量不足以覆盖同一调仓协议下的摩擦（H3）。

分年印象（综合报告）：2019 较强；2020–2021 成本后偏弱；2024 Rank IC 转负——线性关系存在年份漂移。

### 7.2 2025 补充样本外（冻结后再测）

| 指标 | 2025 |
|------|-----:|
| 平均 Rank IC | **0.0226** |
| Rank IC 胜率 | 53.16% |
| 毛 Sharpe | **−0.110** |
| 净 5bp Sharpe | **−0.653** |
| 净 5bp 年化 | −6.06% |
| 选定 α | 0.01 |

开发期 vs 2025：

| 指标 | 2019–2024 | 2025 |
|------|----------:|-----:|
| Rank IC | ≈ 0.025 | 0.023（接近） |
| 毛 Sharpe | ≈ 0.40 | −0.11 |
| 净 5bp Sharpe | ≈ −0.22 | −0.65 |

要点：**排序力未消失，组合兑现显著变差**——正 Rank IC 不能保证多空尾部在无成本下仍赚钱。

### 7.3 系数结构（条件关联，非因果）

2025 冻结模型中，缺失指示器系数绝对值往往偏大（如 `inventory_*__missing`），同时 Carry / 基差等经济字段也有非零权重。

答辩表述：

> 联合拟合中的条件关联 ≠ 单字段可交易 Alpha。  
> Ridge 可能利用「有无数据」的结构信息；这与单因子体检中 quality_flag 单独交易往往失效并不矛盾。

## 8. 与同口径模型对照

### 8.1 综合报告主表（统一口径）

| 模型 | Rank IC | 5bps 年化 | 5bps Sharpe |
|------|--------:|----------:|------------:|
| 典型单因子（中位数） | 0.0065 | −4.89% | −0.577 |
| 等权多因子 | 0.0163 | −1.88% | −0.216 |
| **Ridge** | **0.0247** | **−1.79%** | **−0.219** |
| LightGBM | 0.0184 | −2.12% | −0.213 |
| HCGNN | 0.0193 | +3.11% | +0.454 |

### 8.2 2025 三模型对照

| 模型 | Rank IC | 毛 Sharpe | 净 5bp Sharpe |
|------|--------:|----------:|--------------:|
| 等权多因子 | −0.063 | −0.98 | −1.89 |
| **Ridge** | **+0.023** | −0.11 | −0.65 |
| 单因子（predictor 均值） | −0.010 | −0.87 | −1.73 |

启示：

- Ridge 在预测层稳定优于等权与平均单因子。  
- 成本后 Ridge ≈ 等权（开发期），说明**增量几乎全被摩擦吃掉**。  
- HCGNN 等结构模型若胜出，关键差异更可能在换手/路径，而非「线性没学到排序」。

## 9. 局限、风险与后续版本

1. **线性可加假设**：无法表达 Carry×流动性等门槛交互（树模型角色）。  
2. **质量标志进入回归**：系数可吸收缺失结构，解释需谨慎。  
3. **共线性**：系数只表示条件关联，不作因果/独立 Alpha 声明。  
4. **α 时变**：收缩强度漂移，提示关系不平稳。  
5. **执行未完备**：真实费率、冲击、涨跌停、换月冲击未全接入。  
6. **模型层窥视调整未做完**：Deflated Sharpe / SPA / MCS 为后续项；当前为统一口径描述性比较。

版本分工：`linear_ridge_v1` 为协议主线性基准；`linear_ridge_v2` 等变体须单独目录评价，不得回改 v1 协议。

## 11. 答辩可用结论

### 方法

Ridge 是统一协议下的**学习型线性基准**：拟合截面排名、L2 收缩、折内选 α、折外纯测试；与等权的唯一关键差异是权重是否由数据学习。

### 实证

- 开发期 Rank IC ≈ **0.0247**，支持「学习权重能整合弱信号」。  
- 毛 Sharpe ≈ 0.40，但 **5bps 后年化约 −1.79%、Sharpe ≈ −0.219**，与等权几乎打平。  
- 2025 仍有弱正 Rank IC（≈0.023），但毛/净收益为负——**有预测方向，无成本后交易证据**。

### 一句话

> Ridge 证明机器学习（即便只是线性收缩）可以提高弱因子的整合效率，但不能保证改善 5bps 后的投资收益；它是后续一切复杂模型必须对照的线性天花板与地板之间的关键锚点。
