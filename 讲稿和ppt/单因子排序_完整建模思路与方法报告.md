## 1. 研究定位与回答的问题

### 1.1 一句话定义

对每个注册字段**单独**形成横截面排序信号，经方向对齐与 `cs_rank_centered` 后，按统一多空协议评价该字段的样本外 Rank IC 与成本后组合表现。**不做多因子加权或回归。**

### 1.2 它专门回答什么

> **某一个字段单独有没有横截面预测力？在统一执行与成本下能否变成可交易收益？**

| 问题 | 由谁回答 |
|------|----------|
| **某一个字段单独有没有预测力？** | **单因子排序（本模型）** |
| 不挑因子、等权平均够不够用？ | 等权多因子 |
| 数据驱动加权组合如何？ | Ridge / 线性回归 |
| 非线性 / 图 / 时序？ | 树 / HCGNN / Conv–Transformer |

### 1.3 是 / 不是

| 是 | 不是 |
|----|------|
| 92 条并行的「单字段策略」体检 | 一个联合预测黑盒 |
| 识别信号来源与经济叙事入口 | Top-K 合成后再报单一净值 |
| 与 Ridge / 等权同数据、同标签、同执行 | 用 OOS IC 回头筛因子再合成主策略 |
| 传统统计学基准（Baseline） | 已核验实盘 Alpha |

若审核方只要「一条可交易曲线」：开发期优先报告 `warehouse_tightness__csz`；其余字段作为因子体检附表。

## 2. 建模思路与设计哲学

### 2.1 为什么先做单因子

1. **最大透明度**：每个字段的 IC、换手、成本后 Sharpe 可单独审计。  
2. **锚定经济叙事**：Carry、仓单、基差等是否「本身」有信息，不依赖模型加权。  
3. **为多因子提供地板**：若单因子全体很弱，等权/Ridge 的改善才有参照。  
4. **避免联合模型掩盖来源**：联合拟合可能把缺失标志当条件变量用掉，单因子能把「不可交易的结构」暴露出来。

### 2.2 设计原则

- **逐字段独立评价**，`select_top_factors=false`，不在样本外按 IC 再筛 Top-K 合成组合。  
- **经济叙事主看 36 个 predictor**；quality_flag / risk / conditional 单独披露，不作主 Alpha。  
- **报告两类口径**，避免误读：  
  - A. 代表性单因子策略（成本后最优 predictor）  
  - B. Predictor 宇宙中位数（「典型单因子」而非冠军）

### 2.3 与因子筛选 A–F 分级的关系

综合报告对 57 个概念因子另有预测力 / 可交易性 / FDR 三重门槛分级（A=0）。  
单因子排序模型是**同一执行协议下的实现层体检**：把注册字段逐一跑通多空回测，为叙事提供逐字段数字，而不是另起一套选股规则。

## 3. 数据基座与特征接口

### 3.1 数据来源

| 项目 | 设定 |
|------|------|
| 交接包 | `training_handoff/` |
| 特征 / 标签 / 注册表 / 折 | 与 Ridge、等权相同 |
| 品种 / 区间 | 30 品种；开发矩阵约 2015-01-05 — 2024-12-31 |

本模型**不**从原始库现场重算因子。

### 3.2 输入字段结构

| usage_type | 数量 | 角色 |
|------------|-----:|------|
| predictor | 36 | 主叙事对象 |
| quality_flag | 45 | 多为 `__missing`，不作主 Alpha |
| risk | 6 | 风险类 |
| conditional | 5 | 条件类 |
| **合计** | **92** | 与 Ridge 全量接口一致 |

### 3.3 特征预处理（handoff 已完成）

| 项目 | 设定 |
|------|------|
| 去极值 / 标准化 | 同日横截面 Median–MAD Z-Score，clip \([-5,5]\) |
| 缺失 | 连续特征可填截面中位数，并保留 `__missing` |
| 中性化 | 未做行业/板块全局中性化 |
| 模型侧 | 仅方向对齐 + `cs_rank_centered`；缺失样本该日该品种不参与该字段排序 |

### 3.4 标签

\[
y^{(5)}_{i,T}
=
\frac{\mathrm{Open}_{c,T+6}}{\mathrm{Open}_{c,T+1}}-1
\]

主标签 `future_return_5d`；对照 `target_cs_rank_5d` 不参与选因子。

## 4. 信号构造方法（核心公式）

### 4.1 处理流水线（每个字段独立）

```text
字段 f
  ↓
① 方向 d ∈ {+1,-1,0}
     catalog 优先；d=0 时仅用该折训练窗日均 RankIC 符号冻结
  ↓
② signed = f × d
  ↓
③ prediction = cs_rank_centered(signed) ∈ [-1, 1]
  ↓
④ 统一执行引擎：前后 20% 多空 · 5 日调仓 · 0/3/5/10 bps
  ↓
该字段自己的 Rank IC / 年化 / Sharpe / 回撤
```

### 4.2 方向规则

- \(d=+1\)：`signed = raw`  
- \(d=-1\)：`signed = -raw`  
- \(d=0\)：仅训练窗估计符号，测试窗冻结，**不看测试年**

### 4.3 刻意不做的事

- 不做多因子加权 / 回归  
- 不做 OOS Top-K 再选择  
- 不做 EMA 时间平滑  
- 不做流动性尾部剔除（主回测）  
- 不把 2025 混入开发评价后再回头改方向

### 4.4 配置摘要

| 项 | 值 |
|----|-----|
| `score_transform` | `cs_rank_centered` |
| `use_all_registered_features` | `true`（92） |
| `select_top_factors` | `false` |
| `holding_days` / `rebalance_frequency_days` | 5 / 5 |
| `long_short_fraction` | 0.2 |
| `base_cost_bps_one_way` | 5 |
| `annualization` | 50.4 |

## 6. 组合执行与成本协议

与等权 / Ridge **完全同一执行引擎**：

| 项目 | 设定 |
|------|------|
| 时点 | T 收盘信号 → T+1 开盘 |
| 多空 | 最高/最低各 20%；两侧绝对权重各 0.5；组内等权 |
| 调仓 | 每 5 日；持有 5 日 |
| 门槛 | 调仓日有效品种过少则跳过；日度 IC 有效样本 ≥ 5 |
| 成本 | 主口径单边 5bps；`net = gross − TO × c/10000`；调仓日往返换手取 2.0 |
| 敏感性 | 0 / 3 / 5 / 10 bps |

## 7. 实证结果

### 7.1 开发期样本外（2019–2024）

#### A. 代表性策略：`warehouse_tightness__csz`

| 指标 | 3bps | 5bps（主口径） |
|------|-----:|---------------:|
| 年化收益 | 2.36% | **0.34%** |
| Sharpe | 0.364 | **0.053** |
| 最大回撤 | −11.27% | −15.23% |
| 5 日 Rank IC | 0.0230 | 0.0230 |

#### B. Predictor 中位数（36 个经济因子）

| 指标 | 数值 |
|------|-----:|
| 5 日 Rank IC 中位数 | **0.0065** |
| 3bps 年化 / Sharpe 中位数 | −2.87% / −0.340 |
| **5bps 年化 / Sharpe 中位数** | **−4.89% / −0.577** |
| 5bps 净 Sharpe > 0 的 predictor | **1 / 36**（仓单紧张度） |

约 **61%** 的 predictor 样本外日均 Rank IC 为正，但成本后绝大多数转负。

#### C. Rank IC 头部（≠ 成本最优）

| 字段 | Rank IC | 毛 Sharpe | 净 5bp Sharpe |
|------|--------:|----------:|--------------:|
| carry_annualized__csz | 0.0291 | 0.279 | −0.272 |
| basis_fresh__csz | 0.0285 | 0.463 | −0.168 |
| warehouse_tightness__csz | 0.0230 | 0.831 | **0.053** |

说明：仓单紧张度并非 Rank IC 最高，但换手与收益幅度组合更能承受成本——**预测力 ≠ 可交易性**。

### 7.2 2025 补充样本外（冻结后再测）

| 口径 | 平均 Rank IC | 平均净 5bp Sharpe | 净 5bp>0 占比 |
|------|-------------:|------------------:|--------------:|
| 全体 92 字段 | −0.0150 | −2.47 | 10.9% |
| **36 predictor** | **−0.0098** | **−1.73** | **6/36（16.7%）** |
| quality_flag | −0.0434 | −3.58 | 0% |

2025 净 5bp 仍正的 predictor（节选，同向较干净者优先）：

| 字段 | Rank IC | 净 5bp Sharpe | 净 5bp 年化 |
|------|--------:|--------------:|------------:|
| multi_horizon_trend__csz | 0.0497 | 0.64 | 5.46% |
| volume_price_divergence_20__csz | 0.0350 | 0.41 | 4.20% |
| warehouse_tightness__csz | 0.0644 | 0.15 | 0.74% |

解读：2025 更像「确认地板偏弱、少数结构仍存活」，不是「单因子体系整体过关」。  
`quality_flag` 几乎全灭，不可与 predictor 混谈策略好坏。

## 8. 与同口径模型对照

| 模型 | Rank IC | 5bps 年化 | 5bps Sharpe | 角色 |
|------|--------:|----------:|------------:|------|
| 典型单因子（中位数） | 0.0065 | −4.89% | −0.577 | 本模型 B 口径 |
| 仓单紧张度（代表） | 0.0230 | 0.34% | 0.053 | 本模型 A 口径 |
| 等权多因子 | 0.0163 | −1.88% | −0.216 | 全体平均 |
| Ridge | 0.0247 | −1.79% | −0.219 | 学习权重 |
| HCGNN | 0.0193 | +3.11% | +0.454 | 结构 + 低换手 |

含义：单因子证明信号弱且成本敏感；等权/Ridge 能抬高平均排序，但仍难过 5bps；更复杂模型的优势需另用换手与执行解释。

## 9. 局限、风险与使用边界

1. **产出是 92 条并行策略**，不是一条联合净值；引用时必须区分中位数 vs 代表因子。  
2. **quality_flag 高 IC 或高亏损**可能来自缺失结构，不具独立交易含义。  
3. **多重比较**：逐字段评价存在窥视风险；综合报告另用全库 FDR（A=0）约束「确认 Alpha」。  
4. **执行未完备**：真实费率、冲击、涨跌停、换月附加成本未全接入。  
5. **年份漂移**：开发期头部与 2025 存活名单不完全重合（如多周期趋势在 2025 更突出）。

## 11. 答辩可用结论

### 方法

单因子排序是**无参数、逐字段**的横截面体检：方向对齐 → 排名 → 统一多空；不联合拟合、不在 OOS 上 Top-K。

### 实证

- 约六成 predictor 有弱正 Rank IC（中位约 0.0065），但 **5bps 下仅 1/36 净 Sharpe 为正**（仓单紧张度，年化约 0.34%）。  
- 2025 冻结补充整体更差；少数结构（多周期趋势、仓单、量价背离）仍存活。  
- 贡献是：**证明信号来源弱而异质，并给多因子模型提供可审计地板**——不是商业 Alpha 清单。

### 一句话

> 单因子排序说明：中国商品期货存在弱横截面信息，但「典型单因子」过不了 5bps；成本后唯一稳健转正的经济代表是仓单紧张度，其余多为体检附表而非可交易策略。
