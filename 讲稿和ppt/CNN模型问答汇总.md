> 整理范围：本轮对话中关于 CNN 完整架构、因果主力、三类特征、组合层原理的问答。  
> 说明：文中“当前整合模型”指 59 维输入、20 日标签、轻量 Conv–Transformer 多任务框架；历史版本绩效协议不完全一致，不能当作严格消融结论。

## 问题 1：CNN 完整模型架构、详细建模过程与思路是什么？

### 核心结论

当前正式方法是：**因果主力面板 + 59 维 × 20 日序列 → 轻量 Conv–Transformer 多任务双头**，不是早期三层纯 CNN。

### 要解决什么问题

在 30 个商品期货上，用日频多维信息预测**未来截面相对强弱**，而不是猜绝对涨跌。

核心约束：

- 低信噪比、非平稳、横截面只有约 30 个品种
- 必须因果点时：决策日 \(t\) 收盘后出信号，\(t+1\) 开盘执行
- 拟合好 ≠ 样本外赚钱；成本与换手会吃掉毛收益

设计直觉：

- **Conv1d**：共享参数抓局部形态（如“动量升 + 持仓升 + 波动降”）
- **单层 Transformer**：在 20 日短窗口上做全局依赖
- **多任务双头**：方向分类 + 幅度回归，避免只被极端收益主导

### 迭代路径

| 阶段 | 思路 | 关键变化 |
|------|------|----------|
| V1 | 打通端到端链路 | 5 因子、三层 1D-CNN、次日收益；训练能收敛但样本外常亏 |
| V3–V4 | 标签与系统化 | 5 日累计超额；扩展窗口；EMA/缓冲；强度加权；GMM 压力降杠杆 |
| V5 | 表示能力升级 | 7 个原始量价；Conv1d + 单层 Transformer；分类+回归双头 |
| V6 | 特征扩维 | 旧交接包 59 维；dropout↑；换手下降，但缺 2025、品种池不一致 |
| **当前** | **数据契约优先于堆层** | 整合 CSV 重建 59 维；标签改 20 日；品种 Embedding 真正接入；净化 40 日 |

原则：先保证点时、标签、品种池、评价口径一致，再谈“Transformer / 59 因子是否有增量”。

### 最终模型结构

**输入张量**

\[
X \in \mathbb{R}^{B \times 59 \times 20}
\]

- \(B\)：batch；\(F=59\)：特征通道；\(T=20\)：回溯交易日
- 59 = **45 个连续特征** + **14 个缺失质量标志**
- 连续特征：日内历史变换 → 横截面 MAD 稳健标准化 → 板块去均值 → 缺失填 0；缺失由 `__missing` 标志告诉网络

**前向结构**

```text
X [B,59,20]
    │
    ▼  Conv1d(k=3, pad=1) → GELU → Dropout
H⁰ [B,48,20]          # 局部嵌入，通道 59→48
    │
    ▼  transpose
   [B,20,48]
    │
    ▼  品种 Embedding(30→8) 在时间维复制，与 H⁰ 拼接 → Linear 投回 48
H¹ [B,20,48]          # 共享规律 + 品种条件响应
    │
    ▼  1× TransformerEncoder (4 heads, FF=96, pre-norm, GELU, dropout=0.40)
   [B,20,48]          # 20 日内全局注意力
    │
    ▼  时间平均池化 → LayerNorm → Dropout
h  [B,48]             # 样本级共享表示
    │
    ├─ 分类头 Linear → a     (方向 logit)
    └─ 回归头 Linear → ŷ_reg (超额幅度)
```

关键公式：

1. 局部卷积：\(H^{(0)}=\mathrm{Dropout}(\mathrm{GELU}(\mathrm{Conv1d}_{k=3}(X)))\)
2. 品种融合：\(H^{(1)}_{i,t}=W_f[H^{(0)}_{i,t}; e_{p_i}]+b_f\)
3. 单层 4-head scaled dot-product 注意力
4. 双头：\(a_i=w_c^\top h_i+b_c,\quad \hat y^{\mathrm{reg}}_i=w_r^\top h_i+b_r\)

**为何轻量**：\(T=20\) 时单层注意力已是全局感受野；再加深主要加方差，样本撑不住。

### 标签与损失

- 主标签：从执行日开盘起未来 **20 段 open-to-open** 几何累计收益，再做**执行日截面去均值**得 \(y^{\mathrm{reg}}\)
- 分类标签：\(y^{\mathrm{cls}}=\mathbf{1}(y^{\mathrm{reg}}>0)\)
- 多任务损失：

\[
\mathcal{L}=0.7\,\mathrm{BCE}(a,y^{\mathrm{cls}})+0.3\,\mathrm{Huber}(\hat y^{\mathrm{reg}},y^{\mathrm{reg}})
\]

- 交易信号（经验门控）：

\[
s_i=\sigma(a_i)\cdot\hat y^{\mathrm{reg}}_i
\]

### 核心超参（当前整合配置）

| 项 | 值 |
|----|-----|
| 输入 | `[B,59,20]` |
| 卷积 / 模型维 | \(k=3\), \(D=48\) |
| 品种嵌入 | 8 |
| Attention | 4 heads / 1 layer / FF 96 |
| Dropout | 0.40 |
| Batch / 轮次 | 512 / max 40，早停耐心 7 |
| 优化 | AdamW，lr=\(10^{-3}\)，weight decay=\(10^{-3}\) |
| 训练抽样 | 每 5 个交易日取一个完整截面 |
| 内验证 | 尾部 15%，净化 40 日 |
| 种子 | 42 |

### 建模全链路

**A. 因果数据**

1. 合约日表（约 84.7 万行，2015–2025）
2. 用滞后成交量/持仓选主力，换月需活跃度超阈值（约 1.10×）
3. 收益按当时真实主力合约记账，减轻换月价差伪收益

**B. 特征工程**

三类经济来源打进同一张量（详见问题 3）。

**C. 防泄漏训练**

- 外层年度扩展窗口：2015–2021→测 2022；…；2015–2024→测 2025
- 训练标签 `exit_date` 必须早于测试年起点
- 重叠标签：训练日步长 5；拟合与验证间 40 日净化
- 早停只看训练窗内验证损失；选定轮数后在全训练窗重拟合
- DataLoader 不打乱时间顺序

**D. 组合层**

详见问题 4。回测仍逐日记账，不是机械持有 20 日。

### 设计优先级

1. 点时正确（特征与主力早于执行）
2. 标签与评价一致（20 日预测 + 统一费用/IC）
3. 容量匹配样本（轻量网络 + 强正则 + 早停）
4. 可交易性（降换手、流动性、压力门控）
5. 最后才是“加深网络 / 堆注意力”

### 边界说明

- 历史绩效（V3/V5/V6）协议不完全一致，不能当严格架构消融
- 当前 20 日整合模型：方法与代码契约已写清，但正式与之绑定的回测输出未必已落盘，不宜直接报“当前模型年化/Sharpe”
- 历史共同现象：改进后毛收益与换手有改善，但对 3–5bp 成本仍很敏感

## 问题 2：用滞后成交量/持仓选主力，换月需活跃度超阈值（约 1.10×），避免“收盘后才知道的主力身份”泄漏——这是什么？

### 一句话

不是随便用成交量选主力，而是：**用昨天的量仓决定今天的主力身份，且新合约要明显更活跃（约 1.1 倍）才换月**，这样回测里不会偷看“当天收盘后才确定”的主力信息。

### 问题出在哪

商品期货同一品种有很多到期月合约。研究里通常只盯一条“主力连续”价格序列。

常见做法：某日收盘后，看**当天**谁成交量/持仓量最大，就定谁是主力。

若你又用**同一天收盘后的特征**去预测，就会出问题：

- 当天盘中还不知道最终谁是主力
- 但回测里你已经用了“收盘后才统计出来”的主力身份
- 等于模型在用**收盘后才可知**的信息做决策

这就是“收盘后才知道的主力身份”泄漏（look-ahead / 点时错误）。

### 项目怎么改

代码不直接用当天活跃度，而用**滞后一天**：

- 活跃度 \(A = \text{持仓量} + 0.25\times\text{成交量}\)
- 决策日 \(t\) 选主力时，只看各合约的 \(A_{t-1}\)（昨天收盘后就已知）

因此：\(t\) 日收盘做特征、选主力，信息都只来自 \(t\) 及以前，不会用到“\(t\) 日当天最终谁最大”。

### 为什么还要 1.10× 阈值

如果昨天谁大就立刻换主力，会天天抖动。所以加了换月门槛（默认 `roll_switch_ratio = 1.10`）：

- 当前主力先尽量保持
- 只有**更远月**合约的滞后活跃度**超过当前主力的 1.10 倍**，才切换
- 另外限制临近到期、禁止无理由滚回更近月

这是在用一点“换月迟钝”，换取：

1. 点时更干净
2. 主力序列更稳、换手更少

代价：真实市场可能已开始迁仓，规则还多撑几天旧合约——研究上可接受，实盘要再评估。

## 问题 3：三类经济来源打进同一张量——这是什么？

三类分别是：

1. **价格路径与风险**：动量、趋势效率、波动、偏度
2. **期限结构与库存**：roll yield、仓单/库存水平与变化
3. **交易行为与信息质量**：量仓、Amihud、缺失标志

### 一句话

这是特征工程的经济逻辑：用价格风险、期限结构/库存、交易与数据质量三类变量，共同刻画商品期货收益来源，再一起送进 CNN，让网络学它们的非线性组合，而不是只靠几个动量因子。

### 为什么要分三类

商品期货涨跌通常不只看“涨了几天”，还受三件事影响：

1. 价格自己怎么走（趋势、波动、极端）
2. 供需紧不紧（近远月价差、仓单、库存）
3. 市场好不好交易、信息齐不齐（量仓、冲击成本、数据是否缺失）

模型吃的是过去 20 天、每天 59 维的一张“小图”。三类特征一起喂进去，是为了让卷积/注意力能学它们的**共同变化**。

### 三类分别是什么

#### 1. 价格路径与风险

描述“价格怎么走、风险大不大”。

| 例子 | 含义 |
|------|------|
| 动量 5/10/20/60/120 | 过去一段时间涨了多少 |
| 趋势效率 | 净涨跌相对总波动：走势顺不顺、干不干净 |
| 实现波动 / 下行波动 | 波动大不大、下跌时更吓人吗 |
| 偏度 | 收益分布偏不偏（尾部风险） |
| 振幅、K 线实体、收盘–结算差 | 当日路径形态 |

对应直觉：趋势延续、波动状态、尾部风险。

#### 2. 期限结构与库存

描述“持有期货相对现货/远月贵不贵、库存紧不紧”。

| 例子 | 含义 |
|------|------|
| roll yield | 主力与次主力价差折算的期限结构收益（contango/backwardation） |
| roll 的 5/20 日变化 | 曲线在变陡还是变平 |
| 现货动量 | 现货本身强弱（过期观测会过滤） |
| 仓单/库存/可用库存的水平与变化 | 实物宽松还是紧张 |

对应直觉：便利收益、持有成本、供需紧张度。

#### 3. 交易行为与信息质量

描述“市场拥不拥挤、好不好成交、今天这条信息靠不靠谱”。

| 例子 | 含义 |
|------|------|
| 成交量、持仓量及其变化 / z-score | 交易活跃、仓位堆积 |
| 量/仓换手 | 相对持仓的交易强度 |
| Amihud | 单位成交额带来的价格冲击（流动性差） |
| 缺失质量标志 `__missing` | 这个基本面今天是不是根本没有可靠观测 |

对应直觉：拥挤、流动性、披露差异。库存/仓单经常缺或陈旧，直接填 0 会被当成“经济含义为零”；所以用缺失标志告诉模型：“这是没数据，不是库存真的是 0”。

### “打进同一张量”是什么意思

每个样本形状是：

\[
X \in \mathbb{R}^{59 \times 20}
\]

- 一个通道：某一个经济指标随时间的序列
- 一个时间步：某一天这 59 个指标的截面快照

所以不是三个模型各吃一类特征，而是**三类信息叠成同一块输入**，由 Conv1d 在局部几天里扫“动量升 + 库存降 + 成交放大”这类共振。

## 问题 4：组合层为什么要这么设计？有什么原理？

组合层要点：

- 信号 3 日 EMA
- 入场：前/后 30% 且同号；退出：40%/60% 宽缓冲（严进宽出）
- 流动性最低 20% 禁止新开
- 按 \(|s|\) 强度加权；正常每侧毛敞口 0.5
- 因果 GMM：用年 \(Y\) 之前数据拟合波动/相关/流动性压力；压力概率 >0.8 时杠杆减半
- 回测仍逐日记账，不是机械持有 20 日——“20 日标签 ≠ 20 日调仓”

### 总原理：预测层 ≠ 交易层

| 层 | 任务 | 优化目标 |
|----|------|----------|
| 模型 | 从特征预测截面强弱 | IC / 损失 |
| 组合 | 把分数变成仓位 | 成本后收益、回撤、可执行 |

CNN 给分数 \(s\)；组合层决定“买不买、买多少、何时砍、压力大不大”。这套规则补的是深度模型天生不管的三件事：**噪声、可交易性、风险状态**。

### 1. 信号 3 日 EMA：压日频噪声

日频 \(s_t\) 很抖，边界附近会今天进明天出。3 日 EMA 做短窗低通滤波：

- 金融信号半衰期往往不是 1 天
- 换手下降，费用侵蚀变小

代价：反应变慢，可能少抓急转弯——用短窗折中。

### 2. 严进宽出：滞回，防抖动

- **入场**：信号在截面前 30% 且 \(>0\)（多），或后 30% 且 \(<0\)（空）
- **退出**：多头跌破 40% 分位才平，空头升破 60% 才平

这是 **hysteresis（滞回）**：进入门槛严、退出门槛宽，避免在阈值附近反复穿越。弱预测 + 高换手时，**少交易比多交易更重要**。

### 3. 流动性最低 20% 禁止新开：剔除“纸面 Alpha”

IC 可能集中在难成交品种上。最低 20% 流动性禁止新开（已有仓按退出线处理）。这是**可交易性约束**：回测里靠薄市场赚到的钱，实盘冲击可能吃掉。

### 4. 按 \(|s|\) 强度加权，每侧毛敞口 0.5

等权会让“刚好进门”的弱信号和强信号一样重。强度加权让幅度信息反映到仓位上（与双头回归一致）；某一侧不够格就不硬凑，允许净敞口偏离 0、保留现金。

### 5. 因果 GMM 压力门控

每日用过去约 20 日的市场波动、品种平均相关、流动性压力，拟合两状态 GMM；**只对测试年 \(Y\) 用 \(Y\) 年之前的数据拟合**，当年只做 transform/预测。压力概率 \(>0.8\) 时杠杆减半。

原理：

- 高波动 + 高相关 + 差流动性 ≈ 系统性压力，截面多空更脆
- 无监督状态机：做风险预算缩放，不声称精确识别“危机”
- “因果拟合”避免用当年测试期信息调风控

边界：门控会同时砍回撤和上涨；不能只因最大回撤下降就说“识别准了”。

### 6. 为何“20 日标签 ≠ 20 日调仓”

- **训练标签**：未来 20 日累计截面超额 → 告诉模型“中期相对强弱”
- **回测记账**：每天用下一段 open-to-open 算盈亏；仓位由分位/缓冲/流动性/GMM **逐日更新**

原理：

- 标签选 20 日：降日频噪声、提高每次交易信息含量（更利费用）
- 持仓不必锁死 20 日：信号半衰期、风险状态、流动性每天都在变
- 若机械持有 20 日，组合规则和标签周期被绑死，无法单独测缓冲/门控的作用

类比：天气预报学的是“未来一周累计降雨”，但你每天仍根据最新预报决定带不带伞，不是周一决定后七天不许改。

### 串成一条逻辑链

```text
模型日频分数噪声大
    → EMA 平滑
分数在阈值附近抖动 + 费用敏感
    → 严进宽出缓冲
纸面收益可能来自难交易品种
    → 流动性过滤
方向对但强弱不同
    → |s| 加权 + 不满仓可留现金
市场压力期截面策略更脆
    → 因果 GMM 降杠杆
标签要稳、执行要活
    → 20日监督，逐日调仓记账
```

**总结**：在低信噪比、高成本的商品期货横截面上，Alpha 往往很弱；组合层用平滑、滞回、可交易性过滤和状态降杠杆，把弱预测变成成本后仍可能存活的敞口。这和“把网络加深一层”是同一量级甚至更重要的工程决策。
