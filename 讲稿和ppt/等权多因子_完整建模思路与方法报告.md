## 1. 研究定位与回答的问题

### 1.1 一句话定义

在事前冻结的候选因子宇宙上，对全部字段做**方向对齐**与**横截面可比化**后，以**相等权重**合成为单一综合分数 `prediction`，再按统一点时、扩展窗口与多空协议评价样本外表现。

### 1.2 它专门回答什么

> **在不做任何因子挑选、不估计回归系数的前提下，把候选宇宙里的信号简单平均，是否仍具有可交易的样本外横截面信息？**

| 问题 | 由谁回答 |
|------|----------|
| 某一个字段单独有没有预测力？ | 单因子排序 |
| 数据驱动加权组合如何？ | Ridge / 线性回归 |
| **不挑因子、等权平均够不够用？** | **等权多因子（本模型）** |
| 非线性阈值 / 产业关系 / 时序表示？ | 树 / HCGNN / Conv–Transformer |

### 1.3 是 / 不是

| 是 | 不是 |
|----|------|
| 候选宇宙内全体因子等权合成 | Top-K、逐步纳入、子集搜索 |
| 权重固定为 \(1/N\) | Ridge / OLS / IC 加权 |
| 折内训练窗**仅**用于未知方向定号 | 用训练/测试表现挑因子或改名单 |
| 多因子朴素地板基准 | 单因子排行榜、已核验实盘策略 |

在综合报告的模型栈中，等权多因子是衡量「**仅靠分散化能否改善**」的地板：若 Ridge 高于等权，说明学习权重有增量；若两者成本后都差，则问题更可能在信号经济强度或执行摩擦，而不只在模型形式。

## 2. 建模思路与设计哲学

### 2.1 为什么先做「全体等权」

1. **最少选择自由度**：不问「该不该丢掉某个因子」，先度量「全放进去平均」的基准水平。  
2. **协议最干净**：后续筛弱、去相关、Top-K、Ridge 都有「无选择」对照。  
3. **可复现**：折与折之间名单不变，报告易读。  
4. **主动接受代价**：弱因子与强因子同权；相关因子会重复计入同一主题——这是要度量的现象，不是实现 bug。

### 2.2 为什么不做子集搜索

若在 \(N\) 个因子中搜索「哪几个放进等权最好」，子集数为 \(2^N-1\)。  
即便较小 \(N\) 也极易过拟合；在样本外或全样本上搜最优子集，等于用评价集做模型选择，结论不可信。

本版原则：

> **不搜索组合，只固定宇宙 + 固定合成。**  
> 宇宙里每一个因子各投一票，票权相同。

### 2.3 设计演化说明（想法稿 vs 落地口径）

早期建模想法曾主张主宇宙仅含 `predictor`（及正交化 predictor），不含 `quality_flag`。  
**实际落地的 v1**（与 Ridge 对齐、综合报告采用）为：

```text
use_all_registered_features = true
→ 注册表全部 92 字段等权
  = 36 predictor + 5 conditional + 6 risk + 45 quality_flag
```

这意味着：缺失指示器与弱字段也进入等权平均。综合报告亦明确：因质量标志被纳入，结果需结合「只含经济 predictor」的敏感性理解；正文主结果以**全量接口**为准。

筛弱 / 去相关后的等权见 `equal_weight_multi_v2`，不替代 v1 地板角色。

## 3. 数据基座与特征接口

### 3.1 数据来源

| 项目 | 设定 |
|------|------|
| 交接包 | `training_handoff/` |
| 特征 | `ml_features_development.csv.gz` |
| 标签 | `labels_development.csv.gz` |
| 注册表 | `ml_feature_registry.csv` |
| 折定义 | `fold_definitions.csv` |
| 品种 / 区间 | 中国商品期货 30 品种；开发矩阵约 2015-01-05 — 2024-12-31 |

本模型**不**从原始库现场重算因子；连续主力→真实合约映射、点时延迟、缺失规则已在交接包内完成。

### 3.2 特征预处理（handoff 已完成）

| 项目 | 设定 |
|------|------|
| 去极值 / 标准化 | 同日横截面 Median–MAD Z-Score，clip 至 \([-5,5]\) |
| 缺失（特征工程） | 连续特征可填截面中位数，并保留 `__missing` 标志 |
| 中性化 | 未做行业/板块全局中性化 |
| 模型侧额外变换 | 方向对齐后做 `cs_rank_centered`，再等权平均 |

### 3.3 标签定义

主标签：`future_return_5d`

\[
y^{(5)}_{i,T}
=
\frac{\mathrm{Open}_{c,T+6}}{\mathrm{Open}_{c,T+1}}-1
\]

- 信号：\(T\) 收盘后形成  
- 入场：\(T+1\) 开盘，固定真实合约 \(c\)  
- 出场：持有 5 个交易日后开盘平仓  
- 对照目标：`target_cs_rank_5d`（仅质量对照，不参与选因子或加权）

## 4. 信号构造方法（核心公式）

### 4.1 处理流水线

```text
注册表 92 字段
    ↓
① 方向对齐（catalog / 训练窗 RankIC）
    ↓
② 同日横截面中心化排名 cs_rank_centered → [-1, 1]
    ↓
③ 对当日非缺失字段等权平均（mean_available）
    ↓
单一 prediction
    ↓
统一执行引擎：前后 20% 多空 · 5 日调仓 · 成本情景
```

### 4.2 方向规则

对每个字段 \(f_i\)：

1. 读取目录 `expected_direction` \(d \in \{+1,-1,0\}\)  
2. 若 \(d=+1\)：`signed = raw`；若 \(d=-1\)：`signed = -raw`  
3. 若 \(d=0\)：仅在该折**训练窗**用日均 Rank IC 符号估计方向，并在测试窗**冻结**（不看测试年）

开发期 / 2025 补充回测中的方向结构示例（2025 冻结结果）：

| 项 | 数量 |
|----|-----:|
| 总字段 | 92 |
| catalog 方向 | 69 |
| 训练窗 RankIC 定方向 | 23 |
| 最终方向 = +1 | 78 |
| 最终方向 = −1 | 14 |

### 4.3 合成分公式

对每个交易日、每个品种：

\[
\mathrm{rank}_{i}
=
\mathrm{cs\_rank\_centered}\big(\mathrm{direction}_i \times \mathrm{factor}_{i}\big)
\in [-1,1]
\]

\[
\mathrm{prediction}
=
\frac{1}{|\mathcal{A}|}
\sum_{i \in \mathcal{A}}
\mathrm{rank}_{i}
\]

其中 \(\mathcal{A}\) 为该日该品种**非缺失**的宇宙因子集合。

| 缺失策略 | 定义 | 角色 |
|----------|------|------|
| `mean_available` | 对可用因子等权平均；全缺则无预测 | **主口径** |
| `require_all` | 宇宙因子必须全部非缺失 | 可选稳健性 |

语义：`prediction` = **该品种在候选宇宙上的平均相对强弱**。

### 4.4 刻意不做的事

- 不做 Top-K / 胜率过滤 / 逐步纳入  
- 不做按 IC、Sharpe、波动的再加权  
- 不做回归、不估计组合系数  
- 不枚举子集  
- 不参考单因子或 Ridge 结果增删宇宙  
- 不在测试窗翻转方向或改宇宙  
- 不对合成分做 EMA / 时间平滑（v1）  
- 不启用流动性尾部剔除（v1 主回测）

### 4.5 配置摘要（`config.json`）

| 项 | 值 |
|----|-----|
| `combination_scheme` | `all_equal` |
| `score_transform` | `cs_rank_centered` |
| `missing_policy` | `mean_available` |
| `use_all_registered_features` | `true`（N=92） |
| `raw_return_column` | `future_return_5d` |
| `holding_days` / `rebalance_frequency_days` | 5 / 5 |
| `long_short_fraction` | 0.2 |
| `base_cost_bps_one_way` | 5 |
| `one_way_cost_bps` | 0 / 3 / 5 / 10 |
| `annualization` | 50.4 |

## 5. 样本外验证与防窥视纪律

### 5.1 扩展窗口

| 验证年 | 训练区间（净化后） | 测试 |
|--------|-------------------|------|
| 2019 … 2024 | 2015 起 → 上年年末 | 当年全年 |
| 2025 | 规则冻结后一次补充/封存测试 | 不得回头改方向或删因子 |

外层净化：`label_end_date_5d < valid_start`（约 5 日 purge）。  
禁止随机切分；禁止用测试年定方向或改宇宙。

### 5.2 防过拟合 / 防窥视机制

| 机制 | 说明 |
|------|------|
| 无参数拟合 | 无损失函数、无 Early Stopping、无超参网格 |
| 权重固定 \(1/N\) | 禁止按 IC/Sharpe 截断或子集搜索 |
| 方向估计限训练窗 | 未知方向不看测试年 |
| 统一执行引擎 | 与单因子、Ridge、树、深度模型同组合/成本 |
| 2025 冻结后再测 | 补充回测不得据此改规则再重报 |

## 6. 组合执行与成本协议

| 项目 | 设定 |
|------|------|
| 信号时点 | T 收盘后等权合成 |
| 交易时点 | T+1 开盘 |
| 多空 | 预测最高 20% 做多、最低 20% 做空 |
| 权重 | 多头合计 0.5、空头合计 0.5；组内等权；净敞口 0 |
| 调仓 | 每 5 个交易日；持有 5 日 |
| 门槛 | 有效品种过少则跳过该调仓日（实现中约 <10） |
| 成本公式 | \(\mathrm{net}=\mathrm{gross}-\mathrm{TO}\times c/10000\)；调仓日往返换手保守取 2.0 |
| 主成本 | 单边 **5 bps**；并列 0/3/10 |

说明：现有回测对普通换手成本做代理控制，未完整接入精确涨跌停与换月冲击。

## 7. 实证结果

### 7.1 开发期样本外（2019–2024）

来源：`equal_weight_multi_v1` 团队规范提交报告 / 综合报告。

| 指标 | 数值 |
|------|-----:|
| 样本外记录 / 交易日 / 调仓日 | 43,234 / 1,450 / 293 |
| 平均使用因子数 | 92.0 |
| 平均 Pearson IC | 0.0186 |
| 平均 Rank IC | **0.0163** |
| Rank IC 胜率 | 53.24% |

成本敏感性：

| 成本 | 年化收益 | Sharpe | 最大回撤 | 胜率 |
|------|--------:|-------:|--------:|-----:|
| 毛收益 | 3.16% | 0.364 | −13.21% | 54.95% |
| 0 bp | 3.16% | 0.364 | −13.21% | 54.95% |
| 3 bp | 0.14% | 0.016 | −18.86% | 53.58% |
| **5 bp（主口径）** | **−1.88%** | **−0.216** | **−24.15%** | **51.88%** |

**解读：** 等权合成具有**弱正预测力**；毛收益尚可，但协议主成本 5bps 下净 Sharpe 转负——「能排序」不等于「能覆盖摩擦」。

### 7.2 2025 补充样本外（冻结后再测）

来源：`supplemental_2025_protocol/等权多因子_2025补充回测报告.md`。

| 指标 | 2025 |
|------|-----:|
| 平均 Rank IC | **−0.0629** |
| Rank IC 胜率 | 39.24% |
| 毛 Sharpe | **−0.984** |
| 净 5bp Sharpe | **−1.891** |
| 净 5bp 年化 | −10.51% |

要点：不仅成本后为负，**毛收益已为负**——问题首先在信号方向/合成质量，而不仅是成本假设。上半年连续偏弱，下半年略有修复，全年累计仍明显为负。

开发期 vs 2025：

| 指标 | 2019–2024 | 2025 |
|------|----------:|-----:|
| Rank IC | ≈ 0.016 | −0.063 |
| Rank IC 胜率 | ≈ 53.2% | 39.2% |
| 毛 Sharpe | ≈ 0.36 | −0.98 |
| 净 5bp Sharpe | ≈ −0.22 | −1.89 |

结论：**全字段等权地板在 2025 外推脆弱**，不宜表述为可交易策略过关。

## 8. 与同口径模型对照

### 8.1 综合报告主表（2019–2025 统一口径叙事）

| 模型 | Rank IC | 5bps 年化 | 5bps Sharpe |
|------|--------:|----------:|------------:|
| 典型单因子（中位数） | 0.0065 | −4.89% | −0.577 |
| 等权多因子 | **0.0163** | **−1.88%** | **−0.216** |
| Ridge | 0.0247 | −1.79% | −0.219 |
| LightGBM | 0.0184 | −2.12% | −0.213 |
| HCGNN | 0.0193 | +3.11% | +0.454 |

含义：

- 相对典型单因子，等权把 Rank IC 从约 0.0065 提到 0.0163 → **分散化有弱增量**  
- 相对 Ridge，等权 IC 更低、成本后几乎打平 → **学习权重有预测增量，但净收益增量很小**  
- 相对 HCGNN，等权输在换手与组合路径，而非「没做机器学习」本身

### 8.2 2025 三模型对照（补充回测）

| 模型 | Rank IC | 毛 Sharpe | 净 5bp Sharpe |
|------|--------:|----------:|--------------:|
| 等权多因子 v1 | −0.063 | −0.98 | −1.89 |
| Ridge v1 | +0.023 | −0.11 | −0.65 |
| 单因子（predictor 均值） | −0.010 | −0.87 | −1.73 |

启示：2025 里「不筛选的等权合成」最差；线性收缩好于盲目等权。

## 9. 局限、风险与后续版本

### 9.1 已知局限

1. **弱因子稀释**：92 字段含大量 quality_flag，与强 predictor 同权，会稀释信号。  
2. **相关重复计入**：同家族多窗口因子放大同一主题；v1 故意不去相关。  
3. **无学习权重**：无法下调失效字段或上调稳健字段。  
4. **换手偏高假设**：调仓日往返换手取 2.0，成本敏感。  
5. **执行未完备**：真实手续费、冲击、涨跌停、换月附加成本未全接入。  
6. **年份漂移**：开发期弱正、2025 转负，说明朴素等权外推不稳。

### 9.2 版本分工

| 版本 | 原则 | 角色 |
|------|------|------|
| **v1（本报告）** | 92 全体等权，无挑选 | 地板基准 |
| v2 | 训练窗筛弱 / 去相关后再等权 | 检验「去噪是否改善」 |
| Ridge | 学习线性权重 | 检验「数据驱动加权是否优于等权」 |

原则：v1 协议不因结果回改宇宙；要改进必须新开版本并单独评价。

## 11. 答辩可用结论

### 11.1 方法结论

等权多因子是**自由度最少的多因子基准**：先方向对齐，再横截面排名，再对可用字段等权平均；不选因子、不估系数、不按测试期调名单。

### 11.2 实证结论

- **开发期（2019–2024）**：Rank IC ≈ 0.0163，说明简单分散化相对典型单因子有弱排序增量；毛 Sharpe ≈ 0.36，但 **5bps 后年化约 −1.88%、Sharpe ≈ −0.216**。  
- **2025 冻结补充**：Rank IC ≈ −0.063，毛/净收益均显著为负，显示全字段等权外推失败。  
- **对照价值**：为 Ridge「学习权重是否增量」、为树/深度模型「复杂结构是否必要」提供地板；当前证据表明——**等权能部分整合弱信号，但不能在主成本下稳定变现。**

### 11.3 一句话

> 等权多因子证明：把 92 个字段一视同仁地平均，样本外仍有弱正排序，但过不了 5bps 成本，且 2025 全面转负；它的贡献是可信的地板基准，不是可交易 Alpha。
