# 一、正则化树模型

## 1.1 问题

PDF 中「正则化树模型」的完整建模架构过程与思路是什么？对这套数据如何评价？

## 1.2 建模思路（为什么做树）

| 对照 | 回答的问题 |
|------|------------|
| Ridge | 线性收缩能否整合弱因子 |
| 树模型 | Carry×流动性×波动×覆盖状态是否存在门槛/交互 |

核心假设：期限结构信号可能只在流动性充足或库存压力高时有效。因此用浅树 + 强正则，而不是深树挖噪声。

约束原则：

- 与 Ridge 共用同一 92 维接口、同一标签、同一扩展窗口、同一执行引擎
- **外层折共享固定参数，不按样本外年份单独调参**（防窥视）
- 最终只比 **样本外 Rank IC + 成本后组合指标**

## 1.3 完整建模架构（端到端）

```text
① 数据层
   聚源实际合约日行情 + TuShare 连续主力
   → 100% 映射到真实可交易合约
   → 30 品种 × 2015-01-05～2025-12-31
   → 品种日面板约 78,112 行

② 特征层（冻结接口）
   预注册 57 概念因子 → 硬门后 47 可计算
   → 横截面 MAD 稳健标准化 + 截断 [-5,5] + 缺失填 0
   → 缺失率≥1% 另加二元缺失标志
   → 冻结 92 维：36 predictor + 5 condition + 6 risk + 45 质量标志
   ※ 禁止用标签 y 选字段

③ 标签层（防泄漏）
   信号：T 收盘形成
   交易：T+1 开盘入场，固定真实合约持有 5 日，T+6 开盘平仓
   y = Open_{T+6}/Open_{T+1} - 1
   purge：label_end_date5d < valid_start

④ 样本切分（扩展窗口）
   2019…2025 逐年 OOS
   训练：2015 起 → 上年年末；验证/测试：当年全年
   2025 仅封存后一次期末考，不回头改参

⑤ 模型层（三类正则化树）
   ┌─────────────┬──────────┬────────┬────────────────────┐
   │ 模型         │ 树数     │ 深度   │ 容量控制            │
   ├─────────────┼──────────┼────────┼────────────────────┤
   │ LightGBM    │ 160      │ 4      │ 行列子采样 + L1/L2  │
   │ XGBoost     │ 160      │ 3      │ 更浅 + 正则         │
   │ 随机森林     │ 60       │ 6      │ 较大叶样本 / 剪枝   │
   └─────────────┴──────────┴────────┴────────────────────┘
   共性：浅树、叶节点最小样本偏大、行列子采样、L1/L2 或代价复杂度剪枝
   输出统一接口：decision_date, product, prediction

⑥ 组合层（统一执行引擎，树模型不自带交易规则）
   每 5 日调仓；有效截面≥8
   多最高 20% / 空最低 20%；两侧绝对权重各 0.5，组内等权
   主成本单边 5bps（并列 0/3/10）

⑦ 评价层
   Rank IC / ICIR；年化、波动、Sharpe、最大回撤、换手
   稳定性门槛：多数年度 Rank IC>0 + 净 Sharpe>0 + HAC 显著（三者需同时满足）
```

## 1.4 三类树各自扮演的角色

1. **LightGBM**：叶子优先增长，对阈值交互更敏感；是树组里最有信息含量的代表。
2. **XGBoost**：更深正则、更浅树（depth=3），检验「再压容量」后交互是否还在。
3. **随机森林**：装袋而非提升，对噪声更钝；若 RF 也强，说明信号偏稳定阈值；若 RF 崩、LGBM 还行，多为弱交互/提升拟合。

三者都是**同一协议下的非线性对照实验**，不是三套独立研究故事。

## 1.5 样本外结果（对「这套数据+这套树」的评价）

| 模型 | 5日 Rank IC | 5bps 年化 | Sharpe | 最大回撤 | 日均换手 |
|------|-------------|-----------|--------|----------|----------|
| LightGBM | **0.0184** | −2.12% | −0.213 | −23.23% | 21.56% |
| 随机森林 | −0.0006 | −5.96% | −0.628 | −32.20% | 22.55% |
| XGBoost | −0.0025 | −1.53% | −0.134 | −17.41% | 20.44% |

对照：Ridge Rank IC **0.0247**（更高），5bps 年化也约 −1.8%。

**结论压成三句：**

1. **预测层**：只有 LightGBM 有弱正排序（0.0184），仍低于 Ridge；XGB/RF 接近零或负 → 非线性并未系统性胜过线性收缩。
2. **组合层**：三者 5bps 全负；LGBM 的 HAC \(p=0.596\)，未过稳定性门槛。
3. **0bps 对照**：LGBM/XGB 年化仅 0.57% / 1.03% → 不只是费用问题，**经济边际本身就太薄**；高换手（~20–23%）在 5bps 下进一步放大损耗。

相对 HCGNN（5bps +3.11%、换手仅 7.23%），树的问题更像是：**分数抖动大 → 尾部 20% 持仓翻得勤 → 摩擦吃掉微弱信号**，而不是「树算法写错了」。

## 1.6 对「这套数据」适不适合树模型的评价

**数据工程层面：质量过关，适合做严肃对照。**

- 合约映射 100%、高质量匹配 ~99%、点时违规 0
- 期限结构/仓单覆盖高，适合作为树的主信号源
- 标签用真实合约、purge、扩展窗口，防泄漏设计正确

**信号结构层面：对树并不友好，报告结果与此一致。**

| 数据特征 | 对树的含义 |
|----------|------------|
| 横截面仅 ~30 品种 | 日截面极小，树易拟合噪声阈值 |
| 典型单因子 Rank IC 中位 ~0.0065 | 信噪比极低，深交互难有稳定边际 |
| A 类因子 = 0；OOS 同号率仅 37.5% | 关系时变，树学到的门槛容易年份漂移 |
| 库存新鲜覆盖仅 ~34%；现货断档 | 缺失标志多（45/92），树可能学「覆盖状态」而非经济机制 |
| 局部 \|ρ\| 可 >0.90 | 冗余特征让树分裂更不稳定 |

一句话：**数据可审计、可复现，但经济信号弱、截面窄、基本面稀疏——这正是正则化树「能表达非线性却难变现」的数据原因。**

# 二、异质持续图神经网络（HCGNN）

## 2.1 问题

异质持续图神经网络的完整建模架构过程与思路是什么？对这套数据与图设定如何评价？

## 2.2 建模思路（为什么做图）

| 对照 | 回答的问题 |
|------|------------|
| Ridge / 树 | 单品种特征能否线性或非线性整合 |
| HCGNN | 原料—中间品—产成品、同板块、共同冲击是否有可学的横截面传导 |

经济动机：商品同时有金融与产业属性；Carry、库存、仓单在单一品种上往往弱，但在产业链邻居之间可能存在共同状态。图模型让每个节点不仅看自己的 92 维因子，还汇总一至二跳邻居。

设计原则：

- 节点 = 期货品种（约 30 个）
- 边 = **异质关系**（产业链 / 同板块 / 动态市场联系），不是把价格相关伪装成真实产业链
- 与 Ridge、树共用同一标签、扩展窗口、多空 20%、5bps 主成本
- 输出仍是统一接口 `decision_date, product, prediction`，胜负由同一执行引擎判定
- **协议 GNN**（每折独立训练）作控制组；**HCGNN** 在扩展窗口上持续更新参数

## 2.3 完整建模架构（端到端）

```text
① 数据 / 特征 / 标签（与树模型同一底座）
   30 品种 · 2015–2025 · 真实合约 5 日开盘到开盘收益
   冻结 92 维节点特征（36 predictor + 5 condition + 6 risk + 45 质量标志）
   信号 T 收盘 → T+1 开盘入场 → 持有 5 日 → purge

② 构图层（Heterogeneous Graph）
   节点 v_i ：品种 i
   关系类型 k ∈ {产业链, 同板块, 动态市场联系}
   邻接 A^{(k)}_t → 归一化拉普拉斯 L^{(k)}_t
   ※ 报告明确：生产配比与完整邻接底表字段级血缘仍待补齐
     → 当前是「项目内冻结的关系输入」，属研究性证据

③ 表示层（二阶谱滤波图卷积）
   H^{(ℓ+1)}_t = σ( Σ_k Σ_{m=0}^{2} θ^{(ℓ)}_{k,m} (L^{(k)}_t)^m H^{(ℓ)}_t W^{(ℓ)}_k )
   含义：对每类关系做 0/1/2 阶谱滤波，再跨关系求和
   → 聚合自身 + 一跳 + 二跳邻居信息
   容量：隐状态 64 维 · 两个图卷积块 · dropout 0.1

④ 多任务约束（HCGNN 相对纯 GNN 的关键差别）
   主任务：5 日收益预测
   辅助任务（依次学习）：CPD、GAP、移动平均（MA）
   目的：减轻只拟合单一收益标签的过拟合，让表示更稳、分数更平滑

⑤ 「持续」学习（Continual）
   扩展窗口逐年推进：保留历史表示，用新增年度样本更新参数
   低学习率 + 正则，抑制灾难性遗忘
   对照：协议 GNN = 每折从零独立训练

⑥ 预测 → 组合（统一执行引擎）
   前后 20% 多空 · 两侧绝对权重各 0.5 · 组内等权
   五个等权持有队列 · 净敞口为零
   主成本单边 5bps（0/3/5/10 敏感性）

⑦ 评价
   Rank IC、年化、波动、Sharpe、最大回撤、胜率、日均换手
   重点看：成本后路径 vs 换手，而不只看 IC 排名
```

架构一句话：**多因子节点特征 → 异质动态图 → 二阶谱滤波时空聚合 → 辅助任务正则 → 逐年持续更新 → 统一组合引擎**。

## 2.4 HCGNN vs 协议 GNN：消融对照

| 组件 | 协议 GNN | HCGNN |
|------|----------|-------|
| 图结构 | 相同 | 相同 |
| 主任务 | 仅 5 日收益 | 5 日收益 |
| 辅助任务 | 无 | CPD + GAP + MA |
| 训练方式 | 每折独立重训 | 扩展窗口持续更新 |
| 设计意图 | 控制组：纯图结构 | 结构 + 表示约束 + 时变适应 |

报告结论：**排序优势在 GNN，净收益/回撤/换手优势在 HCGNN**。

## 2.5 样本外结果（2019–2025，单边 5bps）

| 模型 | Rank IC | 年化 | 波动 | Sharpe | 最大回撤 | 胜率 | 日均换手 |
|------|---------|------|------|--------|----------|------|----------|
| **HCGNN** | 0.0193 | **3.11%** | 7.33% | **0.454** | **−13.44%** | 51.32% | **7.23%** |
| 协议 GNN | **0.0226** | 2.73% | 7.15% | 0.413 | −15.75% | 52.64% | 9.21% |
| Ridge（对照） | 0.0247 | −1.79% | — | −0.219 | — | — | 更高摩擦 |
| LightGBM（对照） | 0.0184 | −2.12% | — | −0.213 | −23.23% | — | ~21.6% |

成本敏感性：

| 单边成本 | HCGNN 年化 / Sharpe | GNN 年化 / Sharpe |
|----------|---------------------|-------------------|
| 0 bps | 4.05% / 0.579 | 3.93% / 0.575 |
| 3 bps | 3.49% / 0.504 | 3.21% / 0.478 |
| 5 bps | 3.11% / 0.454 | 2.73% / 0.413 |
| 10 bps | **2.18% / 0.330** | 1.55% / 0.250 |

期末净值约：HCGNN **1.159**，GNN **1.139**。年度 Rank IC 均不稳定（2021 双双为负）；2021 年后 HCGNN 换手明显更低。

**三句结论：**

1. **预测层**：GNN/HCGNN 的 Rank IC（0.0226 / 0.0193）都**低于 Ridge（0.0247）**，图结构没有赢得「排序冠军」。
2. **组合层**：两者 5bps 均为正，且全程成本情景下 HCGNN 均为正——在统一协议里，这是少有的成本后正路径。
3. **真正增量**：不是更高 IC，而是 **日均换手 7.23%（vs 树 ~21%、GNN 9.21%）** → 摩擦吃得少 → 净收益与回撤更好。

## 2.6 对「这套数据 + 图设定」的评价

**适合图模型的一面**

- 30 个节点恰好构成可解释的小型产业图，计算与解释都可控
- 统一 92 维节点特征、真实合约标签、扩展窗口，保证与其他模型公平比较
- 商品天然有横截面关联，比「把每个品种当独立样本」的树/线性更贴经济结构
- 低换手结果说明：关系平滑后的分数更适合尾部 20% 多空协议

**必须诚实披露的一面**

| 局限 | 含义 |
|------|------|
| 生产配比 / 完整邻接底表血缘未齐 | 不能把边当成「已验证的真实产业链」 |
| 禁止用价格相关冒充产业边 | 正确的研究态度，但当前边定义仍偏研究性 |
| 年度 Rank IC 不稳、2021 为负 | 结构增量有年份依赖，不是稳定 Alpha 证明 |
| 相对 Ridge IC 更低 | 「图更好」主要是**交易层/平滑层**叙事，不是预测精度叙事 |
| 证据强度应标为研究性、有条件 | 不宜答辩说成已商业验证 |

一句话：**节点特征与标签数据质量够做严肃对照；图结构本身尚属「冻结关系输入下的探索结论」，优势更像「关系诱导的分数平滑 → 低换手」，而不是「挖到了更强横截面 Alpha」。**

# 三、两模型横向对照

| 维度 | 正则化树 | HCGNN |
|------|----------|-------|
| 研究问题 | 非线性阈值/交互是否有增量 | 产业横截面关系是否有增量 |
| 输入 | 92 维表格特征 | 92 维节点特征 + 异质边 |
| 容量控制 | 浅树、子采样、L1/L2 | 64 维、2 块、dropout 0.1、辅助任务 |
| 调参纪律 | 外层折固定参数 | 扩展窗口持续更新（非按测试年搜参） |
| 最佳代表 | LightGBM Rank IC 0.0184 | HCGNN 5bps 年化 3.11% |
| 5bps 净收益 | 三者全负 | HCGNN / GNN 均为正 |
| 日均换手 | ~20–23% | HCGNN 7.23% |
| 相对 Ridge | IC 更低，净收益同样差 | IC 更低，但净收益更好 |
| 关键教训 | 能表达 ≠ 能变现 | 赢在换手，不在 IC |
| 数据短板 | 截面窄、信噪比低、关系时变 | 邻接/生产配比血缘未闭合 |

# 四、答辩可直接用的判断

## 4.1 正则化树

- **架构正确**：统一接口 + 浅树正则 + 禁止按 OOS 调参 + 统一执行引擎。
- **科学结论**：非线性门槛在本面板上**没有**带来可交易增量；LightGBM 仅部分支持「排序可学」，不支持「净收益可做」。
- **数据评价**：工程质量高，信息含量弱；树组结果更像对数据现实的诚实映射，而不是模型失败。
- **若要改进**：优先成本感知/低换手目标、减维到经济 predictor，或更强时间正则；而不是加深树或按年份搜参。

## 4.2 HCGNN

- **架构正确**：异质边 + 二阶谱滤波 + 辅助任务 + 持续学习 + 统一执行引擎；并用协议 GNN 做消融。
- **科学结论**：在当前图关系设定下，HCGNN 支持「结构化学习可改善成本后路径」；**不支持**「图模型预测力超过 Ridge」。
- **关键话术**：GNN 赢 IC，HCGNN 赢换手与净收益——说明 H2（组合改善）在组合层成立，代价是必须承认边数据血缘未闭合。
- **若被追问**：下一步应冻结字段级产业邻接与生产配比，再做「有边 / 无边 / 假边」最小消融，才能把增量归因到真实产业链，而不是当前关系定义或辅助任务平滑。

## 4.3 总括一句

> 机器学习能提高弱因子整合效率；树模型证明「非线性不等于净收益」，HCGNN 证明「结构与低换手可以改善成本后路径」——但两者都说明：**可交易价值取决于成本、换手、时间稳定性与数据血缘，而不是模型新颖性本身。**
