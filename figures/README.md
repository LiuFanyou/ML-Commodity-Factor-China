# Experiment Figures

All PNG files are generated by `experiments/plot_results.py` from aggregate experiment outputs.

- `model-comparison-5bps.png`: annual return, Sharpe, and 5-day Rank IC across experiments.
- `cost-sensitivity.png`: annual return across 0/3/5/10 bps one-way costs.
- `nav-curves-5bps.png`: 5 bps daily NAV curves.
- `annual-rank-ic-heatmap.png`: yearly mean 5-day Rank IC by model and experiment.
- `factor-selection-stability.png`: fold frequency of the most consistently selected factors.

No raw market data, feature matrix, target labels, positions, or predictions are stored in this directory.
