## 1. 基础信息与差异声明

**策略/模型名称：** 等权多因子合成 — predictor 先验 + 训练窗剔弱/去相关版（`equal_weight_multi_v2`）

**开发负责人：** [姓名]

**提交日期：** 2026-07-24

### ⚠️ 差异化声明（核心约束）

1. **模型形态：** 仍为 **等权多因子**（`combination_scheme=all_equal`）：方向对齐 → `cs_rank_centered` → **等权平均**。相对 v1：**增加折内训练窗因子筛选**（`selection_mode=train_ic_corr`），**不估计回归系数、不枚举子集、不用样本外 IC/Sharpe 挑因子**。
2. **输入宇宙（先验）：** 仅 `usage_type=predictor`（**36** 字段）；**排除** `quality_flag` / `__missing` / `risk` / `conditional`。与 v1 的 92 全注册表、与 Ridge 全量输入不同——须单独对照，不得与 v1 混称为同一宇宙。
3. **折内筛选（相对 v1 的新增自由度）：**
   - 剔弱：该折训练窗、方向对齐后日均 RankIC ≥ `min_train_rank_ic=0.01`；
   - 去重：按训练窗 RankIC 从高到低贪心纳入；与已入选因子训练窗日均 `|corr|` ≥ `max_pairwise_corr=0.7` 则跳过；
   - 入选名单**允许折间变化**（折均入选约 **12.7**）；审计见 `fold_selected_factors.csv`。
4. **样本外区间：** 扩展窗口 **2019–2024**（`fold_definitions.csv`）。**2025 封存年未进入本 handoff 开发矩阵，本报告不含 2025 OOS。**
5. **信号平滑：** **未**对合成分做 EMA 或其他时间平滑。
6. **截面底池过滤：** **未**额外剔除流动性垫底 20% 品种。
7. **平仓逻辑：** **无**主动止损；仅按 **每 5 个交易日调仓**（调仓日往返换手 `round_trip_turnover = 2.0`）。
8. **主成本口径：** 团队 Base Protocol 主口径单边 **5 bps**；敏感性 **0 / 3 / 5 / 10 bps**。第 6 节按模板展示 **3 bps**，并并列 **5 bps**。
9. **多空分组单调性：** **未计算**。
10. **缺失策略：** `missing_policy=mean_available`（对当日入选且非缺失因子等权平均）。
11. **无其他暗改：** 未更换特殊数据源；未把 2025 混入训练或验证；未按单因子 OOS 短表固定白名单；阈值未做网格搜索。

## 4. 模型架构与训练细节

**模型/算法类型：** **筛弱/去重后的等权多因子**（无回归系数）。每折流程：

1. 先验取全部 predictor；
2. 目录方向；`expected_direction=0` 时仅用训练窗日均 RankIC 符号冻结；
3. 训练窗：剔弱（RankIC ≥ 0.01）→ 贪心相关去重（|corr| ≥ 0.7 跳过）；
4. 测试窗：对入选字段 `signed → cs_rank_centered → mean_available`。

**核心超参数：**

| 项 | 值 |
|---|---|
| `combination_scheme` | `all_equal` |
| `selection_mode` | `train_ic_corr` |
| `candidate_usage_types` | `["predictor"]` |
| `min_train_rank_ic` | `0.01` |
| `max_pairwise_corr` | `0.7` |
| `score_transform` | `cs_rank_centered` |
| `missing_policy` | `mean_available` |
| `long_short_fraction` | 0.2 |
| `holding_days` / `rebalance_frequency_days` | 5 / 5 |
| `annualization` | 50.4 |

**防过拟合机制：**

- 无梯度拟合；合成权重仍固定为入选集上的 \(1/K\)；
- 筛选**禁止**使用测试年 / 全样本 OOS 指标；
- 阈值事前写死，本提交**未**对阈值做网格搜索；
- Expanding-Window + label-end 净化。

**交叉验证方式：** **Expanding-Window**（`fold_2019`…`fold_2024`）。

## 5. 交易执行与回测协议

与 v1 / Base Protocol 同口径：

- T 收盘形成合成分，T+1 开盘调仓；最高/最低 **20%** 多空；组内等权；净敞口 0、总敞口 1；
- 持有 / 调仓 **5** 日；无 EMA、无流动性尾部过滤、无中位数止损；
- 成本：`net = gross − 2.0 × bps / 10000`；敏感性 **0 / 3 / 5 / 10 bps**；主口径 **5 bps**。

## 一句话结论

在统一 Base Protocol 下，对 **36** 个 predictor 做训练窗剔弱（RankIC≥0.01）与相关去重（|corr|≥0.7）后再等权，样本外 RankIC 约 **0.029**、毛 Sharpe 约 **0.66**；单边 **3 bp** 下 Sharpe 约 **0.24**，协议主口径 **5 bp** 下净 Sharpe 约 **−0.04**。相对 92 字段全体等权 v1 有清晰提升，但仍未在 5bp 主成本下稳定盈利。
