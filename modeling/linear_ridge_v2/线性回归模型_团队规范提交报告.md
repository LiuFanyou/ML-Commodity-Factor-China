## 1. 基础信息与差异声明

**策略/模型名称：** 线性回归（Ridge / L2）— predictor 先验 + 训练窗剔弱/去相关版（`linear_ridge_v2`）

**开发负责人：** [姓名]

**提交日期：** 2026-07-24

### ⚠️ 差异化声明（核心约束）

1. **模型形态：** 仍为 **Ridge（L2）线性回归**；预测目标 `target_cs_rank_5d`，策略收益 `future_return_5d`。相对 v1：**先做与等权 v2 相同的训练窗筛弱/去重，再对入选集拟合 Ridge**。**未使用 AIC/BIC 逐步回归，未用样本外 IC/Sharpe 挑因子。**
2. **输入宇宙（先验）：** 仅 `usage_type=predictor`（**36** 字段）；排除 quality_flag / risk / conditional。与 v1 的 92 全量输入不同。
3. **折内筛选：**
   - 剔弱：训练窗方向对齐后日均 RankIC ≥ `min_train_rank_ic=0.01`；
   - 去重：按训练窗 RankIC 贪心纳入；日均 `|corr|` ≥ `max_pairwise_corr=0.7` 则跳过；
   - 入选名单允许折间变化（折均约 **12.7**）；随后在入选集上再选 `alpha` 并拟合。
4. **样本外区间：** **2019–2024**；**不含 2025 OOS。**
5. **信号平滑 / 流动性尾部过滤 / 中位数止损：** 均**未**启用。
6. **主成本口径：** 单边 **5 bps**；敏感性 **0 / 3 / 5 / 10 bps**。
7. **多空分组单调性：** **未计算**。
8. **正则选择：** 外层折训练窗内，用**最后一年**作内部验证，按日均 RankIC 在 `alpha ∈ {0.01, 0.1, 1, 10, 100}` 中选参（仅在入选集上）；测试年不参与选 α。
9. **无其他暗改：** 筛选阈值与等权 v2 对齐且写死；未做阈值网格搜索。

## 4. 模型架构与训练细节

每折：

1. 先验取全部 predictor；
2. 目录方向；`0` 则训练窗 RankIC 符号冻结；
3. 训练窗剔弱 + 相关去重；
4. 入选集上内层验证年选 `alpha`；
5. 全训练窗 Ridge 拟合 → 测试窗预测 → 统一多空执行。

| 项 | 值 |
|---|---|
| `selection_mode` | `train_ic_corr` |
| `candidate_usage_types` | `["predictor"]` |
| `min_train_rank_ic` | 0.01 |
| `max_pairwise_corr` | 0.7 |
| `alpha_grid` | 0.01 / 0.1 / 1 / 10 / 100 |
| 持有 / 调仓 | 5 / 5 |
| `long_short_fraction` | 0.2 |
| `annualization` | 50.4 |

### 6.5 与同口径基准对照（摘要）

| 模型 | 宇宙/入选 | RankIC | 毛 Sharpe | 净 5bp Sharpe |
|---|---|---|---|---|
| Ridge v1（全体 92） | 92 | **0.0247** | **0.397** | **−0.219** |
| **Ridge v2（本提交，筛弱/去重）** | 36 先验 / 折均 12.7 | 0.0217 | 0.350 | −0.261 |
