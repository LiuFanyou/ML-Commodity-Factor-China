你是中国商品期货 Alpha 量化研究员与工程师。请在本仓库内实现并跑通「等权多因子模型 v1（全体等权 / 方案 B）」：在事前固定的候选因子宇宙上，对全部字段做方向对齐与横截面可比化后等权合成单一 prediction，在严格点时规则下做滚动样本外评价与多空回测，输出可复现的配置、代码、产物与中文报告。

============================================================
一、任务目标
============================================================

1. 由注册表规则事前固定候选宇宙 U（默认 predictor + orthogonalized_predictor），对 U 内**全部**字段等权合成，不做 Top-K、不做子集枚举、不按回测表现挑因子。
2. 每个交易日、每个品种：对各宇宙因子定向 → cs_rank_centered → 对非缺失因子等权平均，得到 prediction。
3. 用 prediction 预测下一交易日开盘至收盘收益的相对强弱，并构建市场中性多空组合。
4. 不估计回归系数、不做 IC/Sharpe 加权；本版是「无因子选择的多因子地板基准」。
5. 结论只能来自本仓库真实数据的可复现运行结果，禁止编造回测数字。
6. 禁止阅读或依赖 single_factor_rank / linear_ridge 的报告数字、leaderboard、系数来增删宇宙或改协议。

============================================================

5. 标识列：trade_date, product, sector

============================================================
三、硬性约束
============================================================

1. 点时规则
   - 因子在 T 日收盘后形成；信号仅可用于 T+1 开盘交易。
   - 禁止未来函数：切分、缺测合成、方向选择均不得偷看测试段。

2. 标签
   - 原始收益列：future_return_1d
     （因子形成后的下一交易日开盘至收盘可交易收益）
   - 对照用横截面目标（可选）：target_cs_rank_1d
     = 同日横截面中心化收益排名，映射到 [-1, 1]
   - 本模型不拟合回归目标；IC 与策略收益一律相对 future_return_1d 计算。

3. 样本切分
   - 禁止随机切分。
   - 外层：滚动 3 年训练 → 下 1 年测试。
   - 外层测试年：2018, 2019, 2020, 2021, 2022, 2023, 2024。
   - 训练窗末端净化 purge_trading_days = 1 个交易日。

4. 组合方案（本版写死）
   - combination_scheme = all_equal（全体等权）。
   - 禁止：top_k、selection_metric、子集搜索、相关聚类后再挑、逐步纳入。
   - 「全体」= 主宇宙 U 内全部字段，不等于注册表全部 59 列。
   - 主宇宙：usage_type ∈ {predictor, orthogonalized_predictor}。
   - 不得把 quality_flag 纳入预测宇宙；主口径不纳入 risk / conditional。

5. 代码边界
   - 新建平行实现，可 import factor_modeling.common。
   - 可借鉴 single_factor_rank.py / linear_ridge.py 的写法（切分、方向、报告结构），但**禁止修改**这些文件及其 config / outputs / 报告。
   - 不要为了本任务去改 common.py 的既有函数语义；若必须扩展，仅做向后兼容的新增，且说明理由。优先把等权合成逻辑放在 equal_weight_multi.py 内。

6. 其他禁止项
   - 成本只报告单边 1/3/5 基点敏感性，不得写成已核验的真实手续费或冲击成本。
   - 不得覆盖其他模型已有产物；本模型输出只写 equal_weight_multi_v1 目录。
   - 不得根据跑完后的 OOS 结果回改宇宙定义来「优化」主口径。

============================================================
四、全体等权信号定义
============================================================

设宇宙 U = {f_1, ..., f_N}，N 由注册表 + candidate_usage_types 事前确定，各折相同。

1. 原始信号
   raw_i = 当日字段 f_i 取值。
   - 若字段已是横截面稳健标准化后的 ML 特征，直接使用。
   - 缺测：按缺失策略处理（见下），不要擅自改成用测试段统计填充。

2. 方向对齐（逐因子）
   - 读取 expected_direction（来自 FACTOR_CATALOG，经 source_factor_id 映射；缺省 0）。
   - +1：signed_i = raw_i
   - -1：signed_i = -raw_i
   - 0：仅在该外层**训练窗**内，用该因子相对 future_return_1d 的日均 RankIC 符号定方向（>=0 取 +1，<0 取 -1），并在该折测试窗冻结；禁止用测试段选向。
   - 目录已给 +1/-1 的因子：全程用目录方向，测试窗不改。

3. 单因子可比化
   rank_i = 同日横截面中心化排名(signed_i)，映射到 [-1, 1]
   实现逻辑（与单因子模型一致）：
   - 按 trade_date 分组，对有效样本做 average rank
   - rank = 2 * (rank - (n+1)/2) / (n-1)，n 为当日该因子有效样本数
   - score_transform 默认 cs_rank_centered；若支持 raw_signed 须在 config 写明并在报告披露（主口径仍为 cs_rank_centered）。

4. 等权合成 prediction（主口径 missing_policy = mean_available）
   - 对每个 (trade_date, product)：
     A = 该行在 U 中非缺失的因子集合
     若 |A|=0：prediction = NaN，n_factors_used = 0
     否则：prediction = mean_{i in A}(rank_i)，n_factors_used = |A|
   - 备选（仅稳健性，不替代主口径）：require_all —— 若任一宇宙因子缺失则整行 prediction=NaN。

5. 有效性门槛
   - 组合构建：当日有效品种数（prediction 与 future_return_1d 均非空）< 10，则该日不做组合。
   - IC 计算：当日有效样本 ≥ 5，且 prediction 与 future_return_1d 均有变异，否则跳过该日。

6. 刻意不做
   - 不按训练窗 RankIC 排序截断
   - 不估计回归系数 / 不调 alpha
   - 不枚举 2^N 子集
   - 不读取其他模型结果来改 U

============================================================
五、滚动验证协议
============================================================

配置项（写入 modeling/equal_weight_multi_v1/config.json）：

- model_version: equal_weight_multi_v1
- combination_scheme: all_equal
- data_directory: training_handoff
- feature_file / registry_file / label_file：与 handoff 一致
- raw_return_column: future_return_1d
- model_score_column: prediction
- score_transform: cs_rank_centered
- candidate_usage_types: ["predictor", "orthogonalized_predictor"]
- missing_policy: mean_available
- development_end: 2024-12-31
- outer_test_years: [2018, 2019, 2020, 2021, 2022, 2023, 2024]
- rolling_train_years: 3
- purge_trading_days: 1
- min_ic_samples: 5
- long_short_fraction: 0.2
- one_way_cost_bps: [1.0, 3.0, 5.0]
- annualization: 252
- optional_horizon_columns: []   # 可选；若填写仅附录 RankIC，不改主策略
- output_directory: modeling/equal_weight_multi_v1/outputs
- report_file: modeling/equal_weight_multi_v1/equal_weight_multi_report.md

不要配置 top_k / selection_metric / min_train_ic_hit_rate。

每一外层折：

1. 训练窗 = 测试年之前连续 3 个日历年数据；末端 purge 1 日。
2. 测试窗 = 该测试年全部交易日。
3. 在训练窗内：仅对 expected_direction==0 的宇宙因子解析方向并冻结；宇宙名单不变。
4. 在测试窗：按第四节生成 prediction 与 n_factors_used，拼入全样本外预测长表。
5. 记录每折：test_year、各因子 catalog_direction、resolved_direction、direction_source（catalog|train_rank_ic）。

可选稳健性（不替代主口径；若做须另命令/另输出或清晰分节，且默认本次可不实现）：
- missing_policy=require_all
- candidate_usage_types 仅 ["predictor"]
- 对 future_return_5d / future_return_20d 额外报 RankIC
主策略、主表、主结论仍以 future_return_1d + mean_available + 主宇宙为准。

============================================================
六、组合与成本
============================================================

每个信号日（对合成分，不是对单个因子分别建仓）：

1. 按 prediction 升序排序。
2. 最低 20% 做空，最高 20% 做多（long_short_fraction=0.2）。
3. 多头权重合计 0.5，空头权重合计 0.5；净敞口 0，总敞口 1；组内等权。
4. 次日开盘建仓、当日收盘平仓；往返换手 = 2。
5. 毛收益 = 0.5 * long_mean(future_return_1d) - 0.5 * short_mean(future_return_1d)。
6. 净收益 = 毛收益 - 2 * one_way_cost_bps / 10000，分别计算 1/3/5 bp。

优先复用 factor_modeling.common 中的：
- purge_last_dates
- build_strategy_returns / construct_daily_portfolio
- return_statistics
- daily_correlations / mean_daily_rank_ic（若列名匹配；否则在本模块内做等价实现）

绩效指标至少包含：

预测质量
- 日均 Pearson IC
- 日均 RankIC
- RankIC 胜率
- RankICIR（日均 RankIC / 日 RankIC 标准差）

策略绩效（毛、净1bp、净3bp、净5bp）
- 年化收益、年化波动、Sharpe、最大回撤、总收益、日胜率

覆盖与过程
- 策略交易日数、覆盖率
- n_factors_used 的分布摘要（均值/分位数）
- 宇宙大小 N 与完整名单

可选对照
- prediction 相对 target_cs_rank_1d 的 R²、MAE（不作任何选择依据）
