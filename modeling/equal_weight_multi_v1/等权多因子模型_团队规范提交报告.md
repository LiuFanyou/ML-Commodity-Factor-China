## 1. 基础信息与差异声明

**策略/模型名称：** 等权多因子合成 — 92 注册字段全体等权版（`equal_weight_multi_v1`）

**开发负责人：** [姓名]

**提交日期：** 2026-07-24

### ⚠️ 差异化声明（核心约束）

1. **模型形态：** **全体等权多因子**（`combination_scheme=all_equal`）。对 handoff 注册表全部 **92** 字段逐一方向对齐 → 横截面中心化排名 → **等权平均** 得单一 `prediction`；**不估计回归系数、不做 Top-K、不枚举子集**。与 Ridge（学习权重）/ 单因子（逐字段评价）角色不同，但数据、标签、持有、调仓、多空比例、成本档位同口径。
2. **输入宇宙：** 与 Ridge 一致，使用 `ml_feature_registry.csv` **全部 92** 字段（36 predictor + 45 quality_flag + 6 risk + 5 conditional）。弱因子 / `__missing` 与强因子同权，为本地板基准主动接受的代价。
3. **样本外区间：** 开发评价使用扩展窗口 **2019–2024**（`fold_definitions.csv`）。**2025 封存年未进入本 handoff 开发矩阵，本报告不含 2025 OOS。**
4. **信号平滑：** **未**对合成分做 3 日/5 日 EMA 或其他时间平滑；调仓日直接使用当日等权合成预测排序。
5. **截面底池过滤：** **未**额外剔除流动性垫底 20% 品种（协议稳健性项；主回测未启用）。
6. **平仓逻辑：** **无**「跌破中位数即平」等主动止损；仅按 **每 5 个交易日调仓** 全量换仓（保守假设调仓日往返换手 `round_trip_turnover = 2.0`）。
7. **主成本口径：** 团队 Base Protocol 主口径为单边 **5 bps**；敏感性同时报告 **0 / 3 / 5 / 10 bps**。下文第 6 节按模板展示 **3 bps**，并**并列给出 5 bps（协议主口径）**。
8. **多空分组单调性：** 本版本脚本**未输出**官方 `monotonicity` 字段；第 6 节填「未计算」。
9. **缺失策略：** `missing_policy=mean_available`（对当日可用因子等权平均；全缺失则该行无预测）。**未**在模型侧对特征二次 ffill / 填 0（与 Ridge 回归填 0 不同，因等权需要真实缺失以跳过不可用票）。
10. **无其他暗改：** 未更换特殊数据源；未改主力映射；未把 2025 混入训练或验证；成本公式与统一执行基座一致。

## 3. 因子与特征工程

**输入特征数量：**

- 注册字段合计 **92**：
  - **36** 个 `predictor`（连续经济特征）
  - **45** 个 `quality_flag`（多为 `__missing`）
  - **6** 个 `risk`
  - **5** 个 `conditional`
- 清单：`training_handoff/ml_feature_registry.csv`；本跑宇宙见 `outputs/universe_factors.csv`

**特征预处理（handoff 已完成，本模型不再二次横截面变换）：**

| 项目 | 设定 |
|---|---|
| 去极值 | 同日横截面 **Median + MAD** 标准化后 **clip ±5** |
| 标准化 | 同日横截面 **Median-MAD Z-Score**（`__csz`）；个别条件字段为时序 `__tsz` |
| 缺失（特征工程阶段） | 连续 `__csz`：缺失填当日截面中位数后再标准化，并保留 `__missing` 标志 |
| 中性化 | **未做**行业/板块全局中性化；无全局目标正交 |
| 模型侧额外变换 | 每字段方向对齐后做 **`cs_rank_centered`**，再对可用字段等权平均 |

**预测目标（Label）：**

- 策略收益 / IC 主标签：`future_return_5d`（同一真实合约，**Open-to-Open**，T+1 开盘持有至 T+1+5 开盘）
- 对照目标：`target_cs_rank_5d`（仅作可选质量对照，**不**参与选因子或加权）

## 4. 模型架构与训练细节

**模型/算法类型：** **等权多因子合成**（无参数拟合 / 非树非网络）。对宇宙 \(\mathcal{U}\)（\|U\|=92）：

1. 读取目录期望方向 \(d\in\{+1,-1,0\}\)；
2. 若 \(d=0\)，仅在该折**训练窗**用日均 RankIC 符号估计方向并冻结（**不看测试年**）；
3. 各字段：`signed → cs_rank_centered`；
4. `prediction = mean(可用字段排名)`（`mean_available`）。

**核心超参数：**

| 项 | 值 |
|---|---|
| `combination_scheme` | `all_equal` |
| `score_transform` | `cs_rank_centered` |
| `missing_policy` | `mean_available` |
| `use_all_registered_features` | `true`（N=92） |
| `long_short_fraction` | 0.2 |
| `holding_days` / `rebalance_frequency_days` | 5 / 5 |
| `annualization` | 50.4 |

**损失函数 / 评价标准：** 无训练损失。主评价：样本外 Pearson IC、RankIC、组合年化收益 / 波动 / Sharpe / 最大回撤、成本后指标（0/3/5/10bp）。

**防过拟合机制：**

- 无梯度拟合，无 Early Stopping；
- 权重固定为 \(1/N\)，**禁止**按 IC/Sharpe 截断或子集搜索；
- 方向未知因子的符号估计严格限制在训练窗；
- Expanding-Window + label-end 净化。

**交叉验证方式：** **Expanding-Window**（`fold_2019`…`fold_2024`，2015 起点不变）。

## 5. 交易执行与回测协议

**信号生成与平滑：**

- T 日收盘后特征 → 等权合成 `prediction`；
- **无 EMA / 无多日平滑**；
- T+1 开盘按该信号调仓。

**多空入场阈值：**

- 做多：预测最高 **20%**；做空：预测最低 **20%**；
- 组内等权；多头 0.5 / 空头 0.5；净敞口 0、总敞口 1。

**多空平仓逻辑：**

- 持有 **5** 个交易日；下一调仓日按新预测重建（保守全换仓）；
- **无**盘中中位数止损。

**截面底池过滤：**

- **未启用**流动性尾部剔除。

**单边交易成本（必填）：**

- 敏感性：**0 / 3 / 5 / 10 bps**
- 团队协议主口径：**5 bps**
- 公式：`net = gross − round_trip_turnover × bps / 10000`，调仓日 `round_trip_turnover = 2.0`

## 6. 核心样本外（OOS）评价指标

样本外：**2019–2024**；样本外记录 43,234；交易日 1,450；调仓日 **293**；宇宙 **92**；`n_factors_used` 均值 **92.0**。  
预测层：平均 Pearson IC **0.0186**，平均 RankIC **0.0163**，RankIC 胜率 **53.24%**。  
本提交主协议为 **5 日**持有标签上的 RankIC；**未另报 20 日 RankIC**。

### 6.1 模板要求：单边 3 bps

| 指标 | 数值 |
|---|---|
| 年化收益率（Annual Return） | **0.14%** |
| 最大回撤（Max Drawdown） | **−18.86%** |
| 夏普比率（Sharpe Ratio） | **0.016** |
| 胜率（Win Rate，调仓期收益>0） | **53.58%** |
| 日均换手率（Daily Turnover） | **约 40%**（调仓日往返换手 200%，按 5 日持有均摊：`2.0/5`） |
| 5 日 Rank IC | **0.0163** |
| 20 日 Rank IC | **未计算（本版本未跑 20 日标签）** |
| 多空分组单调性（Monotonicity） | **未计算** |

### 6.2 协议主口径并列：单边 5 bps（Base Protocol）

| 指标 | 数值 |
|---|---|
| 年化收益率 | **−1.88%** |
| 最大回撤 | **−24.15%** |
| 夏普比率 | **−0.216** |
| 胜率 | **51.88%** |
| 5 日 Rank IC | **0.0163**（与成本无关） |

### 6.3 成本敏感性摘要

| 成本 | 年化收益 | Sharpe | 最大回撤 | 胜率 |
|---|---|---|---|---|
| 毛收益 | 3.16% | 0.364 | −13.21% | 54.95% |
| 0 bp | 3.16% | 0.364 | −13.21% | 54.95% |
| 3 bp | 0.14% | 0.016 | −18.86% | 53.58% |
| **5 bp（主口径）** | **−1.88%** | **−0.216** | **−24.15%** | **51.88%** |
| 10 bp | （见 `fold_metrics` / 报告宽表；敏感性已输出） | | | |

### 6.4 与同口径基准对照（摘要）

| 模型 | RankIC | 毛 Sharpe | 净 5bp Sharpe |
|---|---|---|---|
| 等权多因子（本提交，92） | 0.016 | 0.364 | −0.216 |
| Ridge（92） | ≈0.025 | ≈0.40 | ≈−0.22 |
| 单因子（头部 predictor） | ≈0.02–0.03 | 因因子而异 | 多数为负 |

说明：等权合成具有弱正预测力，毛收益 Sharpe 与 Ridge 同量级；在协议主成本 5bp 下净 Sharpe 仍为负。等权作为「无学习权重」的地板基准，便于对照 Ridge 是否真正改善。

## 一句话结论

在统一 Base Protocol 与 `training_handoff` 全量 **92** 字段下，等权多因子合成样本外 RankIC 约 **0.016**、毛 Sharpe 约 **0.36**；单边 **3 bp** 下 Sharpe 接近 0，协议主口径 **5 bp** 下净 Sharpe 为负。本报告作为无挑选、无回归的多因子地板基准提交。
