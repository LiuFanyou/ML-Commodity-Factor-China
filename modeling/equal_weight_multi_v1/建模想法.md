# 等权多因子模型 — 建模想法

> **本版主口径：方案 B — 全体等权（不选因子、不枚举子集）。**  
> 本文档只描述怎么想、怎么定协议，不引用既有单因子或 Ridge 模型的回测数字。  
> 实现时新建平行代码与目录；可复用 `factor_modeling.common`，**不修改**既有模型源码与产物。

---

## 一、模型定位

### 1.1 一句话定义

在预先声明的候选因子宇宙上，对**全部**候选字段分别做方向对齐与横截面可比化，再以**相等权重**合成为单一综合分数 `prediction`，在严格点时与滚动样本外协议下构建市场中性多空组合并评价。

### 1.2 它回答什么问题

本版（全体等权）专门回答：

> **在不做任何因子挑选、不估计回归系数的前提下，把候选宇宙里的信号简单平均，是否仍具有可交易的样本外横截面信息？**

它与其他问题的分工：

| 问题 | 由谁回答 |
|------|----------|
| 某一个字段单独有没有预测力？ | 单因子排序（本版不做） |
| 数据驱动加权组合如何？ | 线性回归 / Ridge（本版不做） |
| 不挑因子、等权平均够不够用？ | **本版（方案 B）** |
| 若以后要挑 Top‑K / 类别配额？ | 另开模型版本，不改本版协议 |

### 1.3 明确边界（是 / 不是）

| 是 | 不是 |
|----|------|
| 候选宇宙内**全体**因子等权合成 | Top‑K、逐步纳入、子集搜索 |
| 权重固定为 \(1/N\)（\(N\)=宇宙大小） | Ridge / OLS / IC 加权 |
| 折内训练窗**仅**用于未知方向定号 | 用训练/测试表现挑因子或改名单 |
| 多因子朴素基准 | 单因子排行榜、已核验实盘策略 |

本版价值：**自由度最少的多因子基准**——名单事前固定，合成规则固定，几乎没有「选模」空间。

## 二、组合原则：为什么是「全体等权」，而不是枚举

### 2.1 枚举为什么不可行、也不该做

若在 \(N\) 个因子中搜索「哪几个放进等权组合最好」，子集数为 \(2^N-1\)。  
即便 \(N=17\) 已约 13 万；若误用全注册表 \(N=59\)，则约 \(2^{59}\)，计算与过拟合都不可接受。

更关键的是方法论问题：在样本外（或全样本）上搜最优子集，等于用评价集做模型选择，结论不可信。

### 2.2 本版采用的原则

**不搜索组合，只固定宇宙 + 固定合成。**

1. **事前声明宇宙** \(\mathcal{U}\)（见第三节）：由注册表 `usage_type` 规则决定，不依赖任何已有模型的回测结果。  
2. **全体入选**：\(\mathcal{S} = \mathcal{U}\)，每一折相同（除非某字段整段不可用，需披露）。  
3. **等权合成**：定向 → 横截面排名 → 简单平均。  
4. **禁止**：按 RankIC/Sharpe 排序截断、相关聚类后再挑、枚举子集、偷看单因子/Ridge 结果来改名单。

「组合」在本版里的含义只有一句：

> **宇宙里每一个因子各投一票，票权相同。**

### 2.3 为什么先做全体等权（方案 B）

- **最少选择自由度**：不问「该不该丢掉某个因子」，先看「全放进去平均」的基准水平。  
- **协议最干净**：后续若做 Top‑K / 去相关 / 类别配额，都有一个「无选择」对照。  
- **实现简单、可复现**：折与折之间名单不变，报告易读。  
- **代价需接受**：弱因子与强因子同权；相关因子会重复计入同一信息（见第九节）。本版主动接受该代价，不在 v1 里用选择去「修」。

## 三、候选宇宙：什么叫「全体」

### 3.1 「全体」≠ 注册表全部 59 列

`ml_feature_registry.csv` 约 59 个字段，但用途不同，不能无差别塞进预测分数：

| usage_type（约） | 角色 | 是否进入本版等权宇宙 |
|------------------|------|----------------------|
| `predictor`（~15） | 主预测字段 | **是（主宇宙）** |
| `orthogonalized_predictor`（~2） | 正交化后的预测字段 | **是（主宇宙）** |
| `risk` / `conditional` | 风险或条件类特征 | 否（主口径）；稳健性可另议 |
| `quality_flag`（~26） | 缺失指示等 | **否**（不是收益预测信号） |

**主口径宇宙 \(\mathcal{U}\)**：

```text
usage_type ∈ {predictor, orthogonalized_predictor}
```

即「全体等权」= **对该预测宇宙内全部字段等权**，而不是对 59 列质量/风险标签一起平均。

宇宙名单在跑模型前由注册表规则生成，写入 config / 报告；**不**根据任何模型的样本外表现增删。

### 3.2 稳健性宇宙（附录，不替代主口径）

仅当主口径跑通后，可另跑、另目录披露（仍不选 Top‑K）：

- 仅 `predictor`（去掉 orthogonalized）  
- 或「除 `quality_flag` 外全部数值特征」——须在报告中强调与主口径不同，且经济含义更杂  

主结论只认主宇宙。

## 四、核心建模直觉

### 4.1 为什么要「先排名、再等权」

不同因子量纲与分布不同，对原始值直接平均没有稳定含义。顺序固定为：

1. **定向**：统一为「分数越大，看多偏好越强」  
2. **可比化**：同日 `cs_rank_centered` → \([-1, 1]\)  
3. **等权平均**：宇宙内各因子对综合分贡献相同  

综合分语义：**该品种在候选宇宙上的平均相对强弱**。

### 4.2 训练窗还做什么（本版很薄）

全体等权**不在训练窗选因子**。训练窗只做一件与信号有关的事：

- 当某因子 `expected_direction = 0` 时，用该折训练窗日均 RankIC 的符号定方向，并在测试窗冻结。

目录已给出 +1 / -1 的因子：全程使用目录方向，测试窗不改。

除此之外，训练窗仍用于：purge 边界、与外层切分一致；**不**用于排序截断或子集搜索。

## 五、信号定义（怎么算综合分）

设候选宇宙 \(\mathcal{U} = \{f_1,\ldots,f_N\}\)，\(N = |\mathcal{U}|\) 事前固定。

### 5.1 方向

对每个 \(f_i \in \mathcal{U}\)：

- 读 `expected_direction`（+1 / -1 / 0）  
- +1：`signed = raw`；-1：`signed = -raw`  
- 0：仅在该折**训练窗**用日均 RankIC 符号定方向，测试窗冻结  

### 5.2 合成分（测试窗；训练窗若需诊断亦可同式计算）

对每个交易日、每个品种：

\[
\text{rank}_{i} = \text{cs\_rank\_centered}(\text{direction}_i \times \text{factor}_{i}) \in [-1, 1]
\]

\[
\text{prediction} = \frac{1}{|\mathcal{A}|}\sum_{i \in \mathcal{A}} \text{rank}_{i}
\]

其中 \(\mathcal{A} \subseteq \mathcal{U}\) 为该日该品种**非缺失**的宇宙因子集合。

说明：

- 主口径是「对可用因子等权」，因此某行有效因子数可能 \(< N\)；权重在剩余因子上仍相等。  
- 若希望严格「固定 \(1/N\)、缺一不可」，见缺失策略备选；**主口径不采用**。

### 5.3 缺失处理（写死）

| 策略 | 定义 | 本版角色 |
|------|------|----------|
| `mean_available` | 对当日该品种非缺失的宇宙因子做等权平均；全缺则无预测 | **主口径** |
| `require_all` | 宇宙因子必须全部非缺失，否则丢弃该行 | 可选稳健性 |

### 5.4 刻意不做的事

- 不做 Top‑K / 胜率过滤 / 逐步纳入  
- 不做按 IC、Sharpe、波动的再加权  
- 不做回归、不估计组合系数  
- 不枚举子集  
- 不参考单因子排序或线性回归的已有结果来增删宇宙  
- 不在测试窗翻转方向或改宇宙

## 六、标签、点时与验证协议

与项目可交易定义对齐（为口径一致，不迁就任何旧结论）：

| 项目 | 设定 |
|------|------|
| 原始收益标签 | `future_return_1d`（下一交易日开盘→收盘） |
| 对照目标（可选） | `target_cs_rank_1d`；仅质量对照，不参与任何选择 |
| 点时 | T 日收盘后形成因子；信号仅用于 T+1 开盘 |
| 外层验证 | 滚动 3 年训练 → 下 1 年测试 |
| 测试年 | 2018–2024 |
| purge | 训练窗末端 1 个交易日 |
| 开发样本截止 | 2024-12-31 |
| 2025 | 不参与定方向、主评价；补充测试须另开目录 |

禁止随机切分；禁止未来函数（定方向不得用测试段）。

## 七、组合与成本

每个信号日，对合成分 `prediction`：

1. 按 `prediction` 排序  
2. 最高 20% 做多、最低 20% 做空（`long_short_fraction = 0.2`）  
3. 多头权重合计 0.5，空头权重合计 0.5；净敞口 0，总敞口 1；组内等权  
4. 次日开盘建仓、当日收盘平仓；往返换手按 2  
5. 净收益 = 毛收益 − 2 × one_way_cost_bps / 10000；报告 1 / 3 / 5 bp 敏感性  

门槛：

- 组合：当日有效品种数 < 10 则跳过  
- IC：当日有效样本 ≥ 5，且预测与收益两侧有变异

## 八、主设定与稳健性

### 8.1 主设定（第一版只认这一套）

| 项 | 取值 |
|----|------|
| 组合方案 | **B：全体等权** |
| 候选宇宙 | `predictor` + `orthogonalized_predictor` |
| 因子选择 | **无**（\(\mathcal{S}=\mathcal{U}\)） |
| `score_transform` | `cs_rank_centered` |
| 缺失 | `mean_available` |
| 方向 | catalog；0 则折内训练窗 RankIC 符号 |
| 标签 / 切分 / 多空 / 成本 | 见第六、七节 |

### 8.2 稳健性（附录，不替代主结论）

- 缺失改为 `require_all`  
- 宇宙改为仅 `predictor`  
- 可选：对 `future_return_5d` / `20d` 额外报 RankIC（主策略仍以 1d 为准）  

**不做**：扫描 Top‑K、在本版内引入选因子逻辑。若以后要做选因子等权，新开 `equal_weight_multi_v2`（或独立命名），并另写建模想法。

原则：主口径极简；敏感性少量、预先声明。

## 九、评价与报告应写什么

### 9.1 预测质量（合成分）

- 日均 Pearson IC / RankIC  
- RankIC 胜率、RankICIR  

### 9.2 策略绩效

毛、净 1bp、净 3bp、净 5bp：年化收益、波动、Sharpe、最大回撤、总收益、日胜率；以及分年表。

### 9.3 过程披露（全体等权特有）

- 宇宙完整名单 \(N\) 个字段及 `usage_type` / 目录方向  
- 每折：方向未知因子的训练窗定号结果（若有）  
- 合成分覆盖率：有效预测行占比；平均每行有效因子数 / \(N\)  
- 明确声明：**本版未做因子挑选，亦未枚举子集**  

### 9.4 报告应回答的问题

1. 全体等权合成分在样本外有没有横截面预测力？  
2. 同一多空规则下毛/净绩效如何？分年是否稳定？  
3. 宇宙与方向是否可复现？覆盖率是否健康？  
4. （附录）换缺失策略或缩小宇宙，结论是否 qualitatively 变化？  

第一版不必与单因子/Ridge 做胜负对比；若对比，另开章节且不得回改本协议。

## 十一、风险与使用边界

1. **弱因子稀释**：全体等权会把预测力弱甚至方向嘈杂的字段与强字段同权平均；这是本版要度量的现象，不是实现 bug。  
2. **相关重复计入**：同家族多窗口因子会放大同一主题；本版不去做相关；若以后要处理，新开版本。  
3. **宇宙定义敏感**：改 `usage_type` 过滤等于换模型；必须事前写死并披露 \(N\) 与名单。  
4. **成本仅为敏感性**：1/3/5bp 非已核验手续费或冲击。  
5. **未覆盖实盘约束**：乘数、涨跌停、容量、真实成交路径未建模。  
6. **2025**：不得混入主评价。

## 十二、建议执行顺序

1. 冻结本文档：方案 B、主宇宙、`mean_available`、cs_rank、1d 标签与滚动协议。  
2. 由注册表生成宇宙名单，写入 config / `universe_factors` 草案。  
3. 实现 `equal_weight_multi.py`：折循环 →（仅）未知方向定号 → 全体等权合成 → 复用 common 回测。  
4. 冒烟：限制年份或检查 `n_factors_used` 分布。  
5. 全量跑通，出报告；确认报告写明「未选因子、未枚举」。  
6. 若需要，再跑附录稳健性；仍不引入 Top‑K。

## 十四、建模哲学（非回测结论）

本版等权多因子的角色是：

> **无因子选择的多因子地板基准**——在事前固定的预测宇宙上，用等权平均检验「把所有候选信号一视同仁地合成」是否仍有样本外信息；  
> 它不替代单因子诊断，也不替代正则化回归；更不通过枚举或事后挑选制造好看的组合。

待主设定跑通后，实证数字只进入运行报告；**不得回写进本文档的协议定义，也不得根据结果改宇宙来「优化」本版。**
