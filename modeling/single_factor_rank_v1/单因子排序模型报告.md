## 一、模型定位

单因子排序是课题的**基准模型之一**：不估计多因子权重、不做回归或树模型拟合，而是检验——

> 若每个交易日仅用某一个字段对 30 个商品品种做横截面排序，并按统一协议做多空，该字段本身是否具有样本外预测力与可交易表现。

它回答的问题是「**哪些经济特征单独有用**」，而不是「**怎样最优组合全部特征**」。后者由等权多因子、Ridge、机器学习模型承担。

| 对比项 | 单因子排序 | Ridge |
|---|---|---|
| 输入 | 92 个注册字段，**逐字段单独**评测 | 92 个字段**联合**进入回归 |
| 预测器 | 方向对齐后的横截面排名 | L2 正则线性预测 |
| 角色 | 可解释基准 / 因子体检 | 线性多因子基准 |

## 三、模型方法

### 3.1 信号构造

对每个候选字段 \(f\)：

1. 读取目录期望方向 \(d\in\{+1,-1,0\}\)（经 `factor_no` 映射）。  
2. 若 \(d=0\)，仅在该折**训练窗**内用日均 RankIC 符号确定方向并冻结，**不看测试年**。  
3. 计算 `signed = f × d`。  
4. 按交易日做横截面中心化排名，得到 `prediction ∈ [-1, 1]`（`cs_rank_centered`）。

### 3.2 标签与切分

| 项目 | 设定 |
|---|---|
| 主标签 | `future_return_5d`（开盘→开盘，同一真实合约） |
| 对照目标 | `target_cs_rank_5d`（仅质量指标，不参与选因子） |
| 外层折 | `fold_2019` … `fold_2024`（2015 起点扩展窗口） |
| 净化 | `label_end_date_5d < valid_start` |

### 3.3 交易与成本（第二共享基座）

| 项目 | 设定 |
|---|---|
| 时点 | T 收盘形成信号，T+1 开盘成交 |
| 持有 / 调仓 | 5 个交易日 |
| 多空 | 预测最高 / 最低各 20%，组内等权 |
| 敞口 | 多空各 0.5；净敞口 0，总敞口 1 |
| 主成本 | 单边 **5 bp** |
| 敏感性 | 0 / 3 / 5 / 10 bp |
| 年化 | 非重叠 5 日收益，`annualization = 50.4` |

调仓日有效品种数 < 10 则跳过组合；日度 IC 要求有效样本 ≥ 5 且两侧有变异。

### 3.4 输出指标

对每个字段单独输出：

- 预测层：Pearson IC、RankIC、IC 胜率、ICIR  
- 组合层：毛收益年化 / 波动 / Sharpe / 最大回撤  
- 成本层：0/3/5/10bp 净 Sharpe 等  
- 稳定性：样本外年份数、RankIC 为正的年数等  

**主结果是每个因子各自的指标**，不是全体因子的中位数。中位数仅作分布摘要。

## 四、结果总览

### 4.1 Predictor（36）样本外摘要

| 指标 | 结果 |
|---|---|
| RankIC > 0 | **22 / 36（61.1%）** |
| RankIC 中位数 | **0.0065** |
| 毛 Sharpe > 0 | **55.6%** |
| 毛 Sharpe 中位数 | **0.022** |
| 5bp 净 Sharpe > 0 | **1 / 36（2.8%）** |
| 5bp 净 Sharpe 中位数 | **−0.577** |

**解读**：截面上存在弱正预测信息，但在「5 日调仓 + 单边 5bp」下，绝大多数**单因子**多空组合无法覆盖成本。唯一净 Sharpe 转正的 predictor 为 `warehouse_tightness__csz`。

### 4.2 为何不看全量 92 榜第一名

全量按 RankIC 排序时，前列常出现 `quality_flag` / `__missing`。它们可能因缺失覆盖模式获得虚高相关，**经济含义弱、成本后亦差**，故：

- 全量 92：用于审计与可复现；  
- 经济讨论：只在 **predictor 且非 missing** 宇宙内做短表。

## 六、与 Ridge 同口径对照

| 项目 | 单因子排序 | Ridge |
|---|---|---|
| 协议 | 相同（5d 标签、扩展窗、5 日持有、5bp） | 相同 |
| 典型 RankIC | 单因子中位约 0.007；头部约 0.02–0.03 | 组合预测平均约 **0.025** |
| 5bp 后 | 绝大多数单因子净 Sharpe < 0 | 组合净 Sharpe 亦为负 |

说明：Ridge 能把分散的弱信号合成接近头部单因子水平的预测力，但在本成本假设下仍难稳定盈利。单因子报告的价值是**定位有用主题**，不是宣称单因子可实盘。

## 八、使用边界

1. 信号仅可用于 T+1 开盘；训练方向选择不使用测试段。  
2. 成本情景不是真实手续费与冲击的核验结果。  
3. 未系统纳入涨跌停、成交容量、合约乘数等实盘约束。  
4. `__missing` 可出现在全量榜，但不应作为「最佳经济因子」。  
5. 2025 不在本 handoff 内，本报告不是封存样本外最终结论。  
6. 高相关字段按协议保留；短表未做「每簇只留一个」，若需可再按聚类压缩。

## 九、结论

1. **模型角色明确**：单因子排序是可解释、可审计的基准，与 Ridge 共用 `training_handoff` 与统一交易协议。  
2. **有弱预测力**：约六成 predictor 样本外 RankIC 为正；头部字段 RankIC 约 0.02–0.03。  
3. **成本约束强**：5bp 后仅个别字段净 Sharpe 转正；中位数显著为负。  
4. **叙事应分层**：全量 92 做审计；正文用 predictor 的 RankIC Top10 + 净 5bp 对照；优先讨论 A∩B 与三表交集字段。  

**一句话**：在统一协议下，中国商品期货截面存在可检出的单因子弱信号（尤其基差、期限结构与拥挤度），但多数单因子策略在 5 日调仓与单边 5bp 下难以成本后盈利；本模型为后续多因子与机器学习比较提供透明基准。
