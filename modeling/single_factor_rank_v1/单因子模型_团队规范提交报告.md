7. **多空分组单调性：** 本版本脚本**未输出**官方 `monotonicity` 字段；第 6 节填「未计算」。
8. **选股/选因子：** 配置 `select_top_factors: false`，**不在样本外按 IC 再筛 Top-K 合成组合**；主结果是 92 字段各自的 OOS 表现（经济叙事优先看 36 个 `predictor`）。

## 3. 因子与特征工程

**输入特征数量：**

- 注册字段合计 **92**：
  - **36** 个 `predictor`（连续经济特征，主叙事对象）
  - **45** 个 `quality_flag`（多为 `__missing` 缺失标志）
  - **6** 个 `risk`
  - **5** 个 `conditional`
- 清单文件：`training_handoff/ml_feature_registry.csv`

**特征预处理（handoff 已完成，本模型不再二次变换）：**

| 项目 | 设定 |
|---|---|
| 去极值 | 同日横截面 **Median + MAD** 标准化后，**clip 至 ±5**（注册 transform：`same_date_cross_sectional_median_MAD_zscore_clip_5_...`） |
| 标准化 | 同日横截面 **Median-MAD Z-Score**（字段后缀 `__csz`）；个别条件字段为时序 `__tsz` |
| 缺失填充（特征工程阶段） | 连续 `__csz`：缺失填**当日截面中位数**后再标准化；并保留对应 `__missing` 标志 |
| 中性化 | **未做**行业/板块全局中性化；无全局目标正交（注册备注：`no_global_target_orthogonalization`） |
| 模型侧额外变换 | 仅将「方向对齐后的因子值」做 **`cs_rank_centered`**（横截面中心化排名 → `[-1, 1]`）作为交易信号 |

**预测目标（Label）：**

- 策略收益 / 原始标签：`future_return_5d`（同一真实合约，**Open-to-Open**，T+1 开盘持有至 T+1+5 开盘）
- 对照排序目标：`target_cs_rank_5d`（仅用于 IC 对照，**不**用于训练加权或选因子）

## 4. 模型架构与训练细节

**模型/算法类型：** 单因子横截面排序（**无参数拟合** / 非树非网络）。对每个字段 \(f\)：

1. 读取目录期望方向 \(d\in\{+1,-1,0\}\)；
2. 若 \(d=0\)，仅在该折**训练窗**用日均 RankIC 符号估计方向并冻结（**不看测试年**）；
3. `signed = f × d`，再做当日 `cs_rank_centered` → `prediction`。

**核心超参数：**

| 项 | 值 |
|---|---|
| `score_transform` | `cs_rank_centered` |
| `long_short_fraction` | 0.2 |
| `holding_days` / `rebalance_frequency_days` | 5 / 5 |
| `annualization` | 50.4（非重叠 5 日收益序列） |
| `select_top_factors` | false（不合成 Top-K） |
| `use_all_registered_features` | true（92 全评测） |

**损失函数 / 评价标准：** 无训练损失。主评价：样本外 **RankIC**、组合年化收益 / 波动 / Sharpe / 最大回撤、成本后 Sharpe（0/3/5/10bp）。

**防过拟合机制：**

- 无梯度拟合，不存在典型 Early Stopping；
- 方向未知因子的符号估计严格限制在训练窗；
- 扩展窗口 + label-end 净化，防止标签穿越验证起点；
- **不在 OOS 上做 Top-K 再选择**（避免信息窥探）。

**交叉验证方式：** **Expanding-Window**（`fold_2019`…`fold_2024`，2015 起点不变，验证年逐年外推）。

## 5. 交易执行与回测协议

**信号生成与平滑：**

- T 日收盘后可用特征 → 方向对齐 → 横截面中心化排名；
- **无 EMA / 无多日平滑**；
- T+1 开盘按该信号调仓。

**多空入场阈值：**

- 做多：预测排名最高 **20%**；
- 做空：预测排名最低 **20%**；
- 组内等权；多头名义 0.5、空头名义 0.5；净敞口 0、总敞口 1。

**多空平仓逻辑：**

- 持有 **5** 个交易日；下一调仓日按新信号重建组合（保守全换仓假设）；
- **无**盘中/每日中位数止损平仓。

**截面底池过滤：**

- **未启用**流动性尾部剔除；仅要求调仓日有效品种数 ≥ 10。

**单边交易成本（必填）：**

- 敏感性：**0 / 3 / 5 / 10 bps**
- 团队协议主口径：**5 bps**
- 成本公式：`net = gross − round_trip_turnover × bps / 10000`，其中调仓日 `round_trip_turnover = 2.0`

## 一句话结论

在统一 Base Protocol 下，单因子排序显示约六成 predictor 具有弱正 5 日 RankIC，但多数无法在 5bp（乃至 3bp）后稳定盈利；成本后唯一转正的经济因子为 `warehouse_tightness__csz`。本报告作为可审计基准提交，供与 Ridge / 机器学习模型同口径比较。
