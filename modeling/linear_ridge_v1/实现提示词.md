## 二、Handoff 接口（固定）

默认目录：`training_handoff/`（config 的 `handoff_directory`）。

必选：

1. `ml_feature_registry.csv`（至少 `feature_name`）
2. `ml_features_development.csv.gz`：`trade_date, product, sector` + 全部注册字段；主键唯一
3. `labels_development.csv.gz`：同主键；至少 `future_return_5d`、`label_end_date_5d`
4. `fold_definitions.csv`：扩展窗口 `fold_2019`…`fold_2024`（训练起点约 2015-01-05）
5. `training_contract.json`（推荐）

模型内存衍生：

- `target_cs_rank_5d` = 对 `future_return_5d` 做同日横截面中心化排名，映射到 `[-1, 1]`

特征已在 handoff 预处理完成。模型侧：

- 设计矩阵缺失填 `0`
- 每折训练窗 `StandardScaler`（只 fit 训练窗）后再 Ridge

**宇宙：注册表全部 `feature_name`（约 92）。不做物理删因子、不做相关簇删除。**

## 三、统一协议（写死）

| 项 | 值 |
|----|-----|
| 策略收益 / IC | `future_return_5d` |
| 训练目标 | `target_cs_rank_5d` |
| 外层 | `fold_definitions.csv` 扩展窗口，OOS 2019–2024 |
| 净化 | `label_end_date_5d < valid_start` |
| 点时 | T 收盘信号 → T+1 开盘 |
| 多空 | 最高/最低各 20%；组内等权；多空各 0.5；净敞口 0、总敞口 1 |
| 持有 / 调仓 | 5 / 5 |
| 调仓换手 | `round_trip_turnover = 2.0` |
| 净收益 | `gross - 2.0 * bps / 10000` |
| 成本 | 0 / 3 / 5 / 10 bp；主口径 5 bp |
| 年化 | `annualization = 50.4` |
| 跳过 | 当日有效品种 < 10 则跳过该调仓日 |
| 2025 | 不参与主评价 / 选参 |

## 四、模型逻辑

算法：`sklearn.linear_model.Ridge`，`fit_intercept=True`，`solver="lsqr"`。  
样本权重：按日等权 `1 / 当日品种数`。

每个外层折：

1. `split_fold` → `outer_train` / `outer_test`（已 purge）
2. **内层选 α**：`outer_train` 最后一年为 inner valid，更早为 inner train（再 purge）；在  
   `alpha_grid = [0.01, 0.1, 1.0, 10.0, 100.0]`  
   上拟合，选 inner valid **日均 RankIC** 最大的 α（平局取更小 α）；失败用 `fallback_alpha=1.0`
3. 用该 α 在整个 `outer_train` 拟合，预测 `outer_test`
4. 用共享 `build_strategy_returns` 回测
5. 记录系数、α 搜索、折指标
