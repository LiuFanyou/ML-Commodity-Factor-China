## 3. 因子与特征工程

**输入特征数量：**

- 注册字段合计 **92**：
  - **36** 个 `predictor`（连续经济特征）
  - **45** 个 `quality_flag`（多为 `__missing`）
  - **6** 个 `risk`
  - **5** 个 `conditional`
- 清单：`training_handoff/ml_feature_registry.csv`

**特征预处理（handoff 已完成，本模型不再二次横截面变换）：**

| 项目 | 设定 |
|---|---|
| 去极值 | 同日横截面 **Median + MAD** 标准化后 **clip ±5** |
| 标准化 | 同日横截面 **Median-MAD Z-Score**（`__csz`）；个别条件字段为时序 `__tsz` |
| 缺失（特征工程阶段） | 连续 `__csz`：缺失填当日截面中位数后再标准化，并保留 `__missing` 标志 |
| 中性化 | **未做**行业/板块全局中性化；无全局目标正交 |
| 模型侧 | Ridge 直接以 92 列数值为自变量；拟合前按折做标准化由 sklearn `Ridge` 在给定 `alpha` 下训练（特征已在 handoff 标准化） |

**预测目标（Label）：**

- 训练目标：`target_cs_rank_5d`（同日横截面中心化未来 5 日收益排名，映射到 `[-1, 1]`）
- 策略评价收益：`future_return_5d`（同一真实合约，**Open-to-Open**，T+1 开盘持有至 T+1+5 开盘）

## 4. 模型架构与训练细节

**模型/算法类型：** **Ridge 线性回归**（L2 正则最小二乘），sklearn 等价实现；全部 92 字段联合输入，输出连续预测分数。

**核心超参数：**

| 项 | 值 |
|---|---|
| `alpha_grid` | `{0.01, 0.1, 1.0, 10.0, 100.0}` |
| `fallback_alpha` | `1.0` |
| 各折选中 α（外层） | 2019–2022：`100`；2023：`1`；2024：`0.1` |
| `holding_days` / `rebalance_frequency_days` | 5 / 5 |
| `long_short_fraction` | 0.2 |
| `annualization` | 50.4 |

**损失函数 / 评价标准：**

- 训练：Ridge 平方损失 + L2 惩罚（`α‖β‖²`）；
- 内部选参：训练窗最后一年日均 **RankIC** 最大；
- 外层评价：Pearson IC、RankIC、组合年化收益 / 波动 / Sharpe / 最大回撤、成本后指标。

**防过拟合机制：**

- **L2 正则**（按折网格搜索 α）；
- Expanding-Window + **label-end 净化**；
- 内层验证年与外层测试年隔离；
- 不在 OOS 上再调 α 或筛特征。

**交叉验证方式：** **Expanding-Window** 外层折 + 各折训练窗内「最后一年」内层验证选 α。

## 5. 交易执行与回测协议

**信号生成与平滑：**

- T 日收盘后特征 → Ridge 预测 → 按预测值横截面排序；
- **无 EMA / 无多日平滑**；
- T+1 开盘按该信号调仓。

**多空入场阈值：**

- 做多：预测最高 **20%**；做空：预测最低 **20%**；
- 组内等权；多头 0.5 / 空头 0.5；净敞口 0、总敞口 1。

**多空平仓逻辑：**

- 持有 **5** 个交易日；下一调仓日按新预测重建（保守全换仓）；
- **无**盘中中位数止损。

**截面底池过滤：**

- **未启用**流动性尾部剔除。

**单边交易成本（必填）：**

- 敏感性：**0 / 3 / 5 / 10 bps**
- 团队协议主口径：**5 bps**
- 公式：`net = gross − round_trip_turnover × bps / 10000`，调仓日 `round_trip_turnover = 2.0`

## 一句话结论

在统一 Base Protocol 下，Ridge 线性回归对 92 字段的联合预测具有弱正样本外 RankIC（约 **0.025**），毛收益 Sharpe 约 **0.40**；在单边 **3 bp** 下 Sharpe 接近 0，在协议主口径 **5 bp** 下净 Sharpe 为负。本报告作为线性多因子基准提交，供与单因子排序及机器学习模型同口径比较。
