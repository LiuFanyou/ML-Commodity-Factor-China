# 机器学习输入报告

## 加工流程

1. 因子在T日收盘后形成，最早T+1开盘使用。
2. 同日横截面使用中位数和MAD去极值，并标准化；该操作不使用未来日期。
3. 标准化后缺失填0，同时在缺失率超过门槛时增加缺失指示器。
4. 高相关因子先聚类；保留代表特征，只有具有增量证据的非代表因子才生成正交残差。
5. 交互仅使用配置中预注册的经济组合，不进行无约束枚举。
6. 模型训练时仍须在每个滚动训练折内重新拟合全局缩放和任何估计参数。
