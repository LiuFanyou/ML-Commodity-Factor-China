## 0. 差异声明

本实验相对团队 Base Protocol 存在以下已登记差异：

1. 主力不按 T-1 持仓量二次重选；采用 TuShare 主力连续序列并映射真实合约。
2. 使用 2015 起点不变的扩展窗口，而非固定三年滚动窗口。
3. 当前正式样本截止 2023-12-31；2024—2025 因现货口径不完整暂不使用。
4. GNN 使用图邻接和可选 CPD/GAP/MA 辅助任务；这些结构不要求其他模型复制。
5. 输入是 47 个可用概念因子展开后的 92 个模型特征，不是 57 或 92 个完整经济因子。
6. 谱滤波采用与二阶谱函数数学等价的拉普拉斯二阶多项式实现。

- 底层数据源：TuShare 期货行情、30 品种实际合约表、现货、库存与仓单、`training_handoff(2)` 因子交接包。
- 研究品种：`30个品种.md` 所列 30 个商品期货。
- 训练/验证：2015 起点不变的扩展窗口，验证年为 2019—2023。
- 最终使用范围：2015-01-05 至 2023-12-31。
- 主键：`trade_date + product`。
- 缺失处理：原始库存不跨品种填充；因子数值缺失填当日横截面中位数并保留缺失标记。

- 标签净化：训练样本满足 `label_end_date_5d < valid_start`；标签不得跨过数据截止日。
