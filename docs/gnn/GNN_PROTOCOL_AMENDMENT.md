# GNN 子项目协议修订与差异声明

版本日期：2026-07-23

本文件不修改团队 `Base Protocol` 原文，而是明确 GNN 子项目的适用口径与差异。正式结果报告必须在开头引用本文件，并逐项披露差异；未在这里登记的实验变更不能直接作为正式主结果。

## 一、继续严格遵守的团队共同口径

1. 研究对象为 `30个品种.md` 所列中国商品期货，研究键为 `trade_date + product`，频率为日频。
2. 信号在 T 日收盘后形成，T+1 日开盘执行。
3. 主标签为同一真实合约从 T+1 开盘至 T+6 开盘的五交易日收益；1 日和 20 日标签只作稳健性分析。
4. 主策略每五个交易日调仓，做多预测前 20%、做空预测后 20%，两侧组内等权，总名义敞口 1、净敞口 0。
5. 主成本为单边 5 bps，并同时报告 0/3/5/10 bps；真实手续费只作辅助诊断，换月成本单列。
6. 随机切分禁止。训练标签结束日必须早于验证期起点，防止标签窗口跨界。
7. 涨跌停、无成交和不可交易标签必须使用与其他模型一致的屏蔽规则。
8. 正式提交至少包含 Markdown 报告、回测指标 CSV、每日净值 CSV、特征清单，并保留逐品种预测表供审计。

## 二、GNN 主实验相对 Base Protocol 的显式差异

### 差异 1：主力合约口径

- Base Protocol 原文：以 T-1 可见持仓量重新选择主力。
- GNN 实际口径：直接采用 TuShare 主力连续序列，并映射到当日真实合约；不再用 T-1 持仓量二次重选。
- 原因：与队友因子挖掘和 `training_handoff(2)` 的标签/特征保持同源，避免 GNN 节点输入与收益标签对应不同的主力序列。
- 风险：TuShare 没有披露主力选择算法及确定时点，因此不能声称 T 日开盘前已知当日主力映射。信号仍在 T 日收盘形成、T+1 开盘执行，以避免当日内前视交易。

### 差异 2：时间切分

- Base Protocol 原文：固定三年训练窗加一年验证窗。
- GNN 实际口径：扩展窗口验证：2015—2018→2019，之后逐年扩展至 2015—2022→2023。
- 原因：GNN 参数更多，固定三年窗口的有效样本偏少；扩展窗口也与 `training_handoff(2)/fold_definitions.csv` 一致。
- 2024—2025 当前不进入正式训练、验证或标签。现货源截至 2023，且用户已明确暂不使用这两年。2025 封存测试待现货口径补齐后再启用。

### 差异 3：模型输入和图结构

- Base Protocol 原文：所有模型必须使用完全相同的特征矩阵。
- GNN 实际口径：底层可观察因子仍来自同一交接包，但 GNN 可以加入由训练期数据构造的图邻接、行业关系、CPD 状态以及持续学习辅助任务。这些是 GNN 架构的一部分，不要求其他模型复制。
- 队友因子库登记 57 个概念因子，其中 47 个通过可计算性和质量门；模型输入为 47 个处理后数值列加 45 个缺失标记，共 92 维。不得把“92 维”写成“92 个经济因子”。
- 图关系、CPD 及任何辅助标签必须只使用当时可见数据。主要可比结论仍以统一的 `future_return_5d` 预测和同一交易回测产生。

### 差异 4：GNN 架构与论文复现

- 日频实现允许将论文谱滤波写成数学等价的二阶多项式 `theta0*X + theta1*L*X + theta2*L^2*X`，避免逐批特征分解。
- 当前网络使用两层时空块；CPD、GAP、MA 是持续学习辅助任务，不能替代五日收益作为正式投资评价目标。
- 架构、损失权重、批量大小、学习率、早停和图构造均属于模型差异，必须在报告中披露并通过滚动验证选择，不能根据 2025 封存结果反向调参。

## 三、采用队友因子口径的细则

1. 基本面没有可靠发布时间时，统一延迟一个交易日可用。
2. 现货最多允许沿用七个自然日；超过期限视为缺失。2024—2025 没有新现货时，基差类特征不得继续使用长期陈旧值。
3. 库存与仓单只能在同品种内按历史观测向后对齐，保留观测日和陈旧度；无序列的品种保持缺失，不得填成零或借用其他品种数值。
4. 模型输入层面的缺失值按交接包执行：处理后的因子值填横截面中位数，同时输入独立缺失标记。当前 92 维交接特征没有 NaN。
5. FU、SC 因汇率不足、I 因干湿吨转换不足，严格基差不作为主因子；必须在特征清单和消融报告中注明。
6. 期限结构因子使用完整可交易合约曲线；主力加下一合约的简化版本只能作为消融。
7. 高相关因子不物理删除，保留聚类编号和代表因子标记，由正则化、图结构或消融分析处理。

## 四、正式与扩展结果的边界

- `protocol_gnn`：只优化五日收益任务，是与其他预测模型比较的 GNN 主结果。
- `hcgnn_continual`：加入 CPD/GAP/MA 持续学习，是论文方法扩展结果。
- 任何特殊图、特殊特征子集、信号平滑、阈值、流动性过滤或替代成本都必须列入报告的差异声明，并与未修改的主协议结果同时给出，不能替代主结果。

## 五、尚未满足、训练前必须补齐的工程项

当前训练入口能输出预测表和预测指标，但还未完整输出统一交易回测所需的 `positions.csv`、`daily_nav.csv`、四档成本敏感性、换手、胜率、分组单调性及 5/20 日 Rank IC。正式重训前必须补齐这些输出，并由同一回测器同时服务 `protocol_gnn` 与 `hcgnn_continual`。
