# 主题七统一实验协议

## 1. 协议目标

本文档用于冻结《机器学习能否改善中国商品期货因子投资？——基于动量、期限结构和流动性特征的研究》的统一研究口径。  
后续所有模型只能更换预测器，不能擅自更改数据口径、策略执行规则和评价标准。

统一协议的目标不是让复杂模型看起来更强，而是保证：

1. 不同模型之间的比较公平。
2. 结果可复现、可审计、可解释。
3. 最终论文结论来自模型能力，而不是回测口径差异。

## 2. 三层共享基座

### 2.1 数据与因子基座

所有模型共享以下固定输入口径：

1. 研究对象：30 个中国商品期货品种。
2. 样本区间：2015-01-05 至 2025-12-31。
3. 训练开发期：2015-01-05 至 2024-12-31。
4. 2025 年用途：封存测试或最终样本外确认，不参与来回调参。
5. 研究单元：`trade_date × product`。
6. 主力合约选择：使用前一交易日可见的持仓量规则，不允许用未来信息。
7. 连续价格用途：只用于因子计算，不直接作为真实交易收益来源。
8. 真实收益来源：具体可交易主力合约的后续可交易收益。
9. 特征文件：统一使用训练交接包中的 `ml_features_development.csv.gz`。
10. 标签文件：统一使用训练交接包中的 `labels_development.csv.gz`。
11. 特征字段：统一使用 `ml_feature_registry.csv` 中 `feature_name` 列全部字段。
12. 索引字段：`trade_date`、`product`、`sector`。

### 2.2 执行策略基座

所有模型输出的预测值，必须映射到同一套交易执行协议：

1. `T` 日收盘后形成信号。
2. `T+1` 日开盘执行建仓或调仓。
3. 主协议默认持有期为 `5` 个交易日。
4. 主协议默认每 `5` 个交易日调仓一次。
5. 主协议默认做多预测排名前 `20%`，做空预测排名后 `20%`。
6. 主协议默认组合权重为组内等权。
7. 主协议默认总名义敞口为 `1.0`，多空对称。
8. 主协议默认单边交易成本为 `5 bps`。
9. 成本敏感性必须额外报告 `0 / 3 / 5 / 10 bps`。
10. 换月额外成本单独记录，不得混入普通调仓成本后失去可解释性。
11. 涨跌停、无成交、极低流动性状态必须有不可成交或延迟成交规则。
12. 任何模型都不得单独享受更宽松的执行假设。

说明：

1. 本研究后续展示的收益类指标，默认都按第二共享基座，也就是本节执行策略基座计算。
2. 除非特别注明，收益类数字均对应统一的 `T日收盘形成信号 + T+1开盘交易 + 5日持有 + 每5日调仓 + 前20%做多/后20%做空 + 组内等权 + 单边5bps` 口径。

### 2.3 评价与审计基座

所有模型共享以下评价标准：

1. 横截面预测指标：Pearson IC、Rank IC、分年 Rank IC。
2. 组合绩效指标：年化收益、年化波动、Sharpe、最大回撤、Calmar、换手率。
3. 成本后指标：至少报告 `0 / 3 / 5 / 10 bps` 四种情景。
4. 统计检验：HAC 标准误和块自助法区间。
5. 稳健性维度：`1日 / 5日 / 20日` 持有期。
6. 板块稳健性：能源、金属、化工、农产品。
7. 可交易性稳健性：剔除最低流动性尾部品种。
8. 信号延迟稳健性：整体延迟 `1` 个交易日。

### 2.4 统一展示指标面板

为了保证汇报、论文正文和实验脚本的输出风格一致，后续结果页统一输出以下三组指标。

#### A. 收益与风险主面板

1. `factor_return`
   定义：样本区间内统一多空组合的累计收益率。
2. `annual_return`
   定义：在第二共享基座口径下，由日度组合收益年化得到的年化收益率。
3. `sharpe`
   定义：统一执行口径下组合日收益的年化夏普比率。
4. `max_drawdown`
   定义：统一执行口径下净值曲线的最大回撤。

#### B. 预测与排序面板

1. `ic_mean`
   定义：样本外 Pearson IC 的时间均值。
2. `rank_ic`
   定义：样本外 Rank IC 的时间均值。
3. `ic_std`
   定义：日度 IC 序列的时间标准差。
4. `ic_ir`
   定义：`ic_mean / ic_std`；若需要年化，必须在附表单独注明。
5. `ir`
   定义：相对统一基准组合的年化信息比率。
   统一基准默认设为 `equal_weight_multi_factor`；若某轮实验没有该基准，则改为相对零基准并明确标注。

#### C. 稳定性与统计显著性面板

1. `p_ic_gt_002`
   定义：日度 IC 大于 `0.02` 的样本占比。
2. `p_ic_lt_neg002`
   定义：日度 IC 小于 `-0.02` 的样本占比。
3. `t_stat`
   定义：主检验对象的 HAC t 统计量。
   主文默认主检验对象为统一执行口径下的日度多空组合收益均值。
4. `p_value`
   定义：与 `t_stat` 对应的 HAC p 值。
5. `monotonicity`
   定义：分组收益与信号排序一致的比例或单调性评分。
   必须在脚本输出中同时记录具体计算方法。

补充说明：

1. 若是单因子结果页，上述指标既可用于单因子排序，也可用于模型预测排序。
2. 若是多模型对比页，所有模型必须按同一基准和同一统计口径输出这组指标。
3. 若额外展示 Calmar、Turnover、Annual Volatility，可作为附加字段，但不能替代上述主面板。

## 3. 冻结的数据口径

### 3.1 固定样本定义

1. 基础研究样本为中国商品期货 30 品种。
2. 样本频率为日频。
3. 数据粒度以品种日为研究面板，以合约日为底层交易明细。
4. 所有后续实验不得混入股票、股指、国债期货或海外商品作为主样本。

### 3.2 固定主力规则

1. 主力选择依据必须来自 `T-1` 日可见持仓量或成交量信息。
2. 若主力切换，则切换日必须被明确记录。
3. 若发生换月，换月收益与普通持有收益必须区分记录。
4. 交割月回退不允许发生；若数据异常导致回退，必须单独审计。

### 3.3 固定特征来源

主线只允许围绕三类核心因子展开：

1. 动量类。
2. 期限结构类。
3. 流动性类。

扩展因子只作为稳健性或附加实验：

1. 波动率。
2. 偏度。
3. 持仓变化。
4. 交互项。
5. 条件变量。

### 3.4 固定标签定义

统一标签集合如下：

1. `future_return_1d`
2. `future_return_5d`
3. `future_return_20d`

主标签固定为：

`future_return_5d`

说明：

1. 主论文比较优先围绕 `5日预测 + 5日持有` 展开。
2. `1日` 和 `20日` 作为稳健性，不作为主结论来源。
3. 若改用其他主标签，必须重跑全部模型，不能只重跑某一个模型。

## 4. 冻结的训练验证协议

### 4.1 切分原则

1. 严禁随机打乱。
2. 采用滚动时间切分。
3. 默认训练窗口为 `3` 年。
4. 默认验证窗口为 `1` 年。
5. 训练集和验证集边界必须设置净化间隔。

### 4.2 默认滚动方案

默认验证滚动如下：

1. 2015—2017 训练，2018 验证
2. 2016—2018 训练，2019 验证
3. 2017—2019 训练，2020 验证
4. 2018—2020 训练，2021 验证
5. 2019—2021 训练，2022 验证
6. 2020—2022 训练，2023 验证
7. 2021—2023 训练，2024 验证

### 4.3 净化规则

1. 使用 `5日` 标签时，训练和验证边界至少净化 `5` 个交易日。
2. 若执行时点额外滞后一天，则推荐净化 `6` 个交易日。
3. 使用 `20日` 标签时，净化间隔应扩展到至少 `20` 个交易日。

## 5. 冻结的策略执行协议

### 5.1 主策略

主策略定义如下：

1. 在 `T` 日收盘后计算全部品种信号。
2. 在 `T+1` 日开盘建立组合。
3. 持有 `5` 个交易日。
4. 每 `5` 个交易日统一调仓。
5. 做多预测排名前 `20%` 品种。
6. 做空预测排名后 `20%` 品种。
7. 多空两侧均为等权。
8. 组合净敞口为 `0`，总敞口为 `1`。

### 5.2 辅助策略

为了稳健性，允许额外运行以下协议，但不能替代主协议：

1. `1日持有 + 每日调仓`
2. `20日持有 + 每20日调仓`
3. `信号整体延迟1日`
4. `剔除最低流动性20%品种`

### 5.3 成交限制

后续接入 `ft_limit` 后，所有模型统一使用以下逻辑：

1. 多头买入若触及涨停且不可成交，则延迟执行或记为未成交。
2. 空头卖出若触及跌停且不可成交，则延迟执行或记为未成交。
3. 平仓若遇涨跌停不可成交，也必须按同一规则延后。
4. 不允许某个模型默认“理论成交”，另一个模型默认“保守成交”。

### 5.4 收益类指标的默认执行口径

为了避免“因子指标好看但不是同一交易协议”这类问题，以下字段默认都必须基于本章主策略输出：

1. `factor_return`
2. `annual_return`
3. `sharpe`
4. `max_drawdown`
5. `ir`

只有 `ic_mean`、`rank_ic`、`ic_std`、`ic_ir`、`p_ic_gt_002`、`p_ic_lt_neg002` 可以在不进入真实持仓的纯预测层先计算；但一旦进入正式结果页，也必须与主策略结果一并展示。

## 6. 冻结的模型比较规则

### 6.1 基准模型

所有正式论文版本至少包含以下基准：

1. 单因子排序
2. 等权多因子
3. 线性回归
4. Ridge
5. Lasso 

### 6.2 机器学习模型

主机器学习组至少包含：

1. LightGBM
2. XGBoost

可选扩展组：

1. Random Forest
2. CNN
3. GNN

### 6.3 公平比较规则

1. 所有模型必须使用同一特征矩阵。
2. 所有模型必须使用同一标签。
3. 所有模型必须使用同一时间切分。
4. 所有模型必须使用同一交易协议。
5. 所有模型必须使用同一成本情景。
6. 所有模型必须输出同一格式的预测表和持仓表。

## 7. 正式输出清单

后续每个模型实验至少输出：

1. `predictions`
2. `positions`
3. `daily_returns`
4. `metrics_summary`
5. `rank_ic_summary`
6. `cost_sensitivity`
7. `feature_importance` 或系数解释
8. `experiment_config`
9. `dashboard_metrics`

论文主报告至少包含：

1. 数据描述表
2. 因子定义表
3. 单因子表现表
4. 多模型比较表
5. 成本敏感性表
6. 持有期稳健性表
7. 分年度表现表
8. 分板块表现表
9. 特征重要性表
10. 因子消融实验表
11. 统一指标面板

## 8. 允许变化与禁止变化

### 8.1 允许变化

1. 更换预测模型。
2. 更换模型超参数。
3. 增加模型解释方法。
4. 增加扩展实验，但必须标注为扩展而非主结果。

### 8.2 禁止变化

1. 只为某个模型单独改样本期。
2. 只为某个模型单独改品种池。
3. 只为某个模型单独改持有期。
4. 只为某个模型单独改成本。
5. 只为某个模型单独改调仓频率。
6. 只为某个模型单独改成交假设。

## 9. 最终一句话原则

后续所有模型只允许竞争“预测能力”，不允许竞争“谁的口径更宽松”。
