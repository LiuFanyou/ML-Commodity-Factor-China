# 原始数据目录

本目录只保存数据源文件，不在这里进行清洗、填补、因子计算或回测。

- `tushare_theme7/`：2015—2025年合约日行情、合约基础信息和交易规则原文件。
- `legacy_2020_2025/`：原有2020—2025年行情、主力、库存、仓单和会员平均成本文件。
- `supplement_2015_2025/`：后续补充的仓单、库存和可用量原文件。

## 使用原则

1. 原始文件不直接修改。
2. 一切研究表输出到 `data_research/`。
3. 不把新旧数据中同名字段自动视为相同口径。
4. 未确认真实公布时间的基本面数据，不得用于点时因子。
